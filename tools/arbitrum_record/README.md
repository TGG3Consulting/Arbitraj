# tools/arbitrum_record — запись ответов своего узла Arbitrum One

Скрипты запускает Тигран на своём сервере: у агентов нет доступа к узлу Arbitrum. Каждый пишет JSON-файлы в
`tests/data/arbitrum_<семейство>_<дата>/` и README.md с блоком и SHA-256; ключей и подписей нет (только чтение).
После записи с тестов семейства снимается `#[ignore]`.

| Файл | Что делает |
| --- | --- |
| `fluid_t1.py` | Fluid DEX T1 (решение 440): состояние всех пулов резолвера на одном блоке и лесенка обменов (swapIn пула → 0x…dEaD, estimateSwapIn резолвера) — для tests/arbitrum_fluid_t1.rs |
