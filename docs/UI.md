# UI — экраны интерфейса

> Каждая фича обязана появиться здесь и в интерфейсе. Экран — один файл в `ui/src/pages/`.

| Экран | Что показывает | Чем управляет | Откуда данные |
| --- | --- | --- | --- |
| Площадки | Подключённые площадки, статус соединений, задержки, разрывы | Включить или выключить площадку или отдельную DEX | api/stream.rs ← gateway |
| Монеты и направления | Справочник, причина исключения монеты | Исключить или вернуть монету или направление, снять карантин | core/registry.rs |
| Живой экран | Текущие спреды по направлениям, кандидаты, причины отказа | Фильтры отображения | core/signal.rs, core/profit.rs |
| Разблокировка | Заблокированы ли секреты | Ввод пароля, добавление и замена секретов (docs/SECURITY.md) | settings/, хранилище секретов |
| Сделки | Идущие сделки по шагам (покупка, перевод, продажа), история, план против факта | Остановка сделки | core/executor.rs, core/ledger.rs |
| Балансы | BingX, кошелёк, монеты в пути, BNB на газ | — | core/ledger.rs |
| Настройки | Все параметры из settings/schema.rs, с описанием и допустимым диапазоном | Изменение на лету | settings/ |
| Правила шлюза | Общие правила и правила площадок | Создать, изменить, выключить правило | gateway/rules.rs |
| Управление | Состояние системы | Старт, стоп, пауза системы, площадки, направления | core/risk.rs |
| Журнал | Ошибки, уведомления, история изменений настроек (кто, что, когда) | Фильтры | storage/, settings/ |

Правило: изменение в интерфейсе применяется сразу, без перезапуска, и пишется в журнал.
