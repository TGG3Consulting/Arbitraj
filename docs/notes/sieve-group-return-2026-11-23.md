# Фикс возврата в верхней границе прибыли

В записи 7230071 от 22.11.2026 03:56:41 UTC для RAIN Gate → BingX верх составил 1.068367 USDT при пороге 1.5 и фиксированных затратах 0.5 USDT. Полный расчёт дал 1.54288349 USDT со строкой возврата 0. Контрольный кандидат дошёл до отдельной проверки лимита выводов (7230076). Прибыль сделки этими строками не подтверждается.

При групповом возврате Live::ret применяет return_b_top_up, где фикс оплачивает первая сделка. Ранее сито всегда вычитало фикс в режиме per_trade. При включённых докупках новая граница затрат использует min(фикс, 0), учитывая обе возможности на протяжении расчёта. Процентная часть проверяется как раньше. При отрицательной доле верх не строится. Затраты, пороги и допуск ордера по-прежнему определяет полный расчёт.

Снимки двух стаканов на всех стадиях исторической проверки в записи отсутствуют. Контроль на фиксированных входах сравнивает обе ветви затрат, включая отрицательный фикс. После установки измерять частоту дополнительных расчётов и случаи core.sieve_violation по направлению.
