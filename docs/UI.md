Правила:
- Изменение в интерфейсе применяется сразу, без перезапуска, и пишется в журнал.
- Везде, где вводится ключ, токен или адрес подключения (биржа, кошелёк, узел BSC, Telegram), есть кнопка «Проверить подключение». Ответ — «Подключено» или точная причина сбоя: единый код ошибки + исходный текст ответа сервиса.

## Что сделано сейчас (ui/, Svelte 5 + Vite)

Запуск и откуда данные — `ui/README.md`. Экран — файл в `ui/src/pages/`, общие элементы — `ui/src/components/`.
На всех экранах: плашка «Система заблокирована», пока секреты не разблокированы; плашка «Нет живой связи», пока нет WebSocket.
Изменения из других вкладок видны сразу (`/api/ws`). Ошибки бэкенда показываются как есть. Значений по умолчанию нет.

В Telegram: сообщение на каждую новую запись, нажатие → вопрос «Да, …» / «Отмена» (как confirm), «Продано вручную» → бот спрашивает сумму (ответить на его сообщение числом), затем «Да, …»; недоступная кнопка не показывается, причина — в тексте; после действия (с экрана или из Telegram) сообщение записи правится «Выполнено: кто, что, итог», кнопки снимаются; второе нажатие — «Уже выполнено». Напоминание каждые `notify.manual_repeat_s` секунд — одно сообщение со списком ждущих записей и их кнопками («1 · Продать сейчас»). Команды бота: /help, /menu и /dev (меню: «Состояние» — как плашка режима, «Ручное управление», «Режим системы» — Старт/Пауза/Стоп, «Площадки и карантин» — снять паузу/карантин, «Лимит дня» — «Сбросить лимит дня»; «Назад», «Обновить»), /status, /manual, /start, /resume, /pause, /stop — всё с подтверждением «Да, …».
