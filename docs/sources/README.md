# docs/sources — исходники контрактов площадок как есть

Исходники контрактов, по которым сверена математика бота, когда их нет в официальных репозиториях на диске, — текст из
верифицированного источника (Sourcify) без изменений, с шапкой-комментарием: адрес, сеть, компилятор, ответ Sourcify
(match / creationMatch / runtimeMatch), дата получения и SHA-256 текста.

| Папка | Что | Решение |
| --- | --- | --- |
| `curve_arbitrum/` | пулы Curve в сети Arbitrum One без исходника в репозиториях curvefi | 481 |
