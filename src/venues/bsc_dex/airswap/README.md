# AirSwap RFQ

Модуль сравнивает предложения маркетмейкеров и проверяет оплату кошельком. Для отправки он использует подписанные условия заявки.

| Файл | Назначение |
| --- | --- |
| mod.rs | Принимает запрос цены и формирует предварительный результат. |
| client.rs | Читает адреса маркетмейкеров и запрашивает условия обмена. |
| indicative.rs | Обрабатывает индикативные цены и доступные размеры. |
| profile.rs | Проверяет контракт площадки и способ исполнения на выбранном блоке. |
| offers.rs | Опрашивает разрешённых маркетмейкеров в пределах общего времени запроса. |
| signed.rs | Проверяет подпись, nonce, остаток, разрешение и результат симуляции. |
| book.rs | Хранит подписанные заявки, сроки и брони. |
| routing.rs | Подбирает заявки на нужную пару, сторону и объём. |
| ranking.rs | Сравнивает исполнимые варианты с учётом затрат на газ. |
| trade.rs | Исполняет выбранную заявку. |
| receipt.rs | Сверяет денежные суммы по сохранённому поручению и квитанции. |
| wire.rs | Описывает ABI обмена и кодирование заказа. |
| tests.rs | Проверяет расчёты, подписанные заявки и архивные квитанции. |
