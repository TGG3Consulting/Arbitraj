# Универсальные адреса вывода HTX

23 ноября 2026 года три сделки XTER → BSC завершились обратной продажей на HTX. В развёрнутой сборке `cc1b4ef0` проверка адреса после покупки обращалась только к списку для монеты. Первая и вторая проверки по XTER вернули пустые массивы. Журнал третьей зафиксировал тот же локальный отказ до отправки заявки на вывод.

Сравнительная проверка тем же ключом дала пустые списки для CAKE в BSC, ARB и ETH в Arbitrum. У USDT было две индивидуальных записи в BSC и двенадцать по всем сетям. Искомого адреса среди них не было. По документированному запросу `currency=t247117` биржа вернула нужный кошелёк в обеих сетях. При фильтрации отдельно по `bep20` и `ARBITRUM` найдено ровно по одной записи, с ответной сетью `bep20` и `arbitrum` соответственно. Статус обеих — `normal`.

Общесетевой код валюты служит только для поиска адреса. Заявка выводит реальную монету и использует её идентификатор сети на HTX. Два одинаковых EVM-адреса в разных сетях требуют отдельных совпадений. При проверке инцидента транзакции не отправляли.
