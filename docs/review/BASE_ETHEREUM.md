## R-01 · 🔴 · Покрытие DEX: «профиль не установлен» без задачи
Правило Тиграна (CLAUDE.md, 20.11.2026): площадка DEX сети работает со ВСЕМИ DEX этой сети; каждый — в таблице покрытия
со статусом; отсутствующее семейство — обязательная задача, не «вне объёма».
Сейчас по таблице GeckoTerminal в `BASE_ETHEREUM_SETTINGS.md`:
- Base: 119 DEX, профиль у 29; без профиля 90, из них у 43 фабрика подтверждена getPair/getPool (baseswap, baseswap-v3,
  alien-base-v3, dackieswap-v3-base, 9mm-v2/v3-base, solidly-v3-base, x7-finance-base …) — похоже, добавляются конфигом
  V2/V3-форка; 17 страниц «не прочитана».
- Ethereum: 80 DEX, профиль у 15; без профиля 65, из них у 20 фабрика подтверждена (shibaswap, sakeswap, fraxswap_ethereum,
  defi_swap, verse, communityv3, orion-ethereum …); 27 страниц «не прочитана».
Предложение: (1) дочитать непрочитанные страницы; (2) DEX с подтверждённой фабрикой стандартного вида — профилем;
(3) остальным — статус «задача T-… : <чего не хватает — математика пулов / источник котировок / нет пулов>» вместо
«профиль не установлен»; (4) порядок — по объёму DefiLlama, не по числу строк страницы (20 — это потолок страницы).
