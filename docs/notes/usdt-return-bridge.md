# Дешёвый возврат USDT BingX → кошелёк BSC через другую сеть и мост

Техдолг, **ПРИОРИТЕТ 1** (Тигран, 02.11.2026). Анализ — Claude, 02.11.2026. Кода нет; это разбор перед решением.

## Проблема (по фактам бота)

- Направление **DEX → BingX** почти не торгуется. За сутки 01–02.11 бот посчитал его **10 110 раз**,
  сигналов было единицы (RVV, DEOD, FAR, CGPT), реальных сделок — ноль.
- Причина — режим `usdt_return.mode = per_trade`: в каждую сделку закладывается возврат выручки на площадку покупки.
  - BingX → DEX: возврат кошелёк → BingX = перевод токена, газ ≈ **0.002 USDT**.
  - DEX → BingX: возврат = **вывод USDT с BingX** в сети BEP20, комиссия **0.15 USDT** (поле `withdrawFee`,
    `config/getall`, запись `tests/data/bingx_2026-10-24/config_getall.json`).
- Пример из журнала (WFI, DEX → BingX): затраты — газ, торговая 0.006, запас r 0.04, **UsdtReturn 0.15**.
  Типичная плановая прибыль на бюджете 44 — 0.02–0.05 USDT, поэтому 0.15 гасит почти все сигналы этой стороны.

## Идея Тиграна

Выводить USDT с BingX в сети с копеечной комиссией (Aptos), а потом мостом переводить USDT из Aptos в BSC
(например, Stargate).

## Факты, которые уже известны

**Комиссии вывода USDT у BingX** (`config/getall`, запись 24.10.2026; живые значения бот читает сам):

| Сеть BingX | withdrawFee | withdrawMin | Вывод |
|---|---|---|---|
| BEP20 (BSC) | 0.15 | 3 | открыт |
| **APT (Aptos)** | **0.01** | 5 | открыт |
| TON | 0.017 | 5 | открыт |
| ARBITRUM | 0.5 | 0.5 | открыт |
| POLYGON | 0.8 | 10 | открыт |
| ERC20 | 1 | 5 | открыт |
| TRC20 | 1.5 | 1.5 | открыт |

Адрес USDT в сети APT у BingX: `0x357b0b74bc833e95a1…` — это **нативный USDT Tether на Aptos** (выпущен в 2024).
Это не старый мостовой lzUSDT.

**Stargate и Aptos:**
- Официальная документация LayerZero о Stargate: «Stargate protocol contracts are EVM-only and live solely on
  LayerZero V2». Пулы протокола (USDC, USDT, ETH) — только в EVM-сетях. **Aptos не EVM**: пулов Stargate для USDT там нет.
- Фронтенд Stargate умеет переводить OFT-токены LayerZero и в не-EVM сети. В январе 2025 Stargate подключил Aptos,
  но там пользователь получает **lzAssets** (мостовые токены LayerZero), а не нативный USDT.
  С марта 2025 есть нативный **USDC** через Circle CCTP.
- **Нативный USDT Aptos → USDT BSC через Stargate не подтверждён** ни одним официальным источником.
- Сторонние обзоры (eco.com) пишут, что Tether-овский USDT0 (OFT LayerZero) к 2026 году «расширен» на Aptos и BNB Chain.
  **Это не официальная документация** — проверить по docs.usdt0.to и живой котировке.
- USDT в BSC (`0x55d398326f99059ff7…`) — это Binance-Peg BSC-USD. Не каждый мост выдаёт именно его: возможны
  USDT0 или мостовые варианты, тогда нужен ещё своп в BSC.

## Экономика (оценка, проверить живыми котировками)

Стоимость маршрута через Aptos: `0.01 (вывод BingX) + газ Aptos (APT) + комиссия моста (% от суммы) +
сообщение LayerZero / комиссия моста фиксированная + газ BSC на получение (если платим мы) + своп, если пришёл
не Binance-Peg USDT`.

- По стороннему обзору, комиссия Stargate ≈ **6 б.п.** (0.06%) плюс газ и сообщение LayerZero. Официально
  комиссия динамическая и считается по маршруту. **Цифру проверить живой котировкой** (`GET https://stargate.finance/api/v1/quotes`).
- Точка безубыточности против прямого BEP20 (0.15 фиксированно), при процентной части p и фиксированной F:
  `0.01 + p·A + F < 0.15` → `A < (0.14 − F) / p`. При p = 0.06% и F ≈ 0.05: **A < ~150 USDT**.
  То есть мост выгоден **только для небольших сумм**. На крупной сумме процент моста дороже фиксированных 0.15 BEP20.
- **Режим «отдельно по порогу»** (`usdt_return.mode = separate`, уже есть в коде) платит 0.15 раз на пачку:
  0.15 на 100 USDT = 0.15%, на 1000 USDT = 0.015%. Это сопоставимо с мостом или дешевле, без новой сети и ключей.
  Стоимость возврата перестаёт входить в каждую сделку.

## Что понадобится, если делать мост

1. Кошелёк в сети Aptos: другой тип ключа (Ed25519), отдельный секрет, газ в APT.
2. Адаптер Aptos: баланс USDT, ожидание зачисления вывода BingX — по официальной документации Aptos.
3. Адаптер моста: котировка, транзакция, отслеживание доставки в BSC — по официальной документации моста.
4. Настройки: сеть вывода у BingX для возврата, порог суммы, допустимая комиссия моста, сроки.
5. Время: вывод BingX в Aptos + мост (по обзорам ~1 мин) + подтверждения. Для возврата капитала это нормально,
   в цену сделки время не входит.
6. Риски: ещё одна сеть и ещё один контракт моста (мосты — частая цель взломов), разные версии USDT,
   ошибки сопоставления адресов.
