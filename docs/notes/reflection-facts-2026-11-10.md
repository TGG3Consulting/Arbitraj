## Чего не удалось получить и почему (дословно)

1. `getReserves()`/`balanceOf()` на блок N−1 для четырёх исторических tx (раздел 1):
   `{"code":-32000,"message":"historical state <hash> is not available"}`. Узел хранит состояние
   только ~последних 128 блоков (head−128 отвечает, head−200 и дальше — та же ошибка). Поэтому
   «излишек на N−1» и величина «(amountIn−нетто−излишек)/брутто» на N−1 не вычислимы.
2. Брутто (amountIn) для SMARS_A: транзакция через Universal Router (selector `0x3593564c`,
   `execute(bytes,bytes[],uint256)`) — сумма из calldata не разбирается стандартно; записано «н/д».
   (Нетто в пул и amountIn монеты из события Swap — получены, см. раздел 1.)
3. PIG, раздел 3: держатель-EOA H не найден — за последние 20000 блоков у PIG ноль событий Transfer
   (`eth_getLogs` пуст). Пункты 3.2–3.4 для PIG не выполнены.
4. Раздел 3.4 для SMARS (перевод от другой пары): не выполнен — вторая пара монеты не выявлялась.
5. `debug_*` на узле отключены (`-32601 the method … does not exist`) — по условию не использовались;
   для разделов 1–4 не требовались.
