# Папка запуска для Windows

Кладётся в архив `arb-windows` сборкой `.github/workflows/windows.yml`.

- `start.bat` — запуск: папка данных `data` рядом, интерфейс на `http://127.0.0.1:8787` (только этот ПК).
  Аргументы запуска — `src/cli.rs`; порт и размер буфера живых потоков можно поменять прямо в `start.bat`.
