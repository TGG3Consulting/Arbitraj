# settings/accounts — кошельки DEX и маппинг (решение 132)

Кошелёк — «счёт» внутри одной площадки DEX. Ключ лежит в зашифрованном файле секретов (docs/SECURITY.md);
здесь — только имя секрета. Доступ — `Store::accounts()`.

| Файл | Что делает |
| --- | --- |
| `mod.rs` | Типы (`Wallet`), строки `dex_dex` и `probe`, чтение: кошельки, строки маппинга, кошелёк переноса, «деньги смешиваются» Решение 401 (ревью t186, Н1): снимок состояния за ArcSwap (`snap`, `publish` после каждой записи в память) и `with_wallet` — кошелёк счёта или строки «Пробы» без замка и без копии записи (горячий путь котировки). |
| `db.rs` | Загрузка из SQLite (`dex_wallets`, `dex_wallet_map`, `dex_wallet_meta`), история (`dex_wallet_history`) |
| `edit.rs` | Добавить, переименовать, задать исполнитель, удалить (запрещено, пока в маппинге или в незавершённой сделке; секрет не удаляется) |
| `edit_map.rs` | Привязка строки маппинга, новый id, общие помощники: история в одной транзакции, журнал `wallets.changed` |
| `chain_exec.rs` | Решение 432: кошелёк глазами площадки DEX сети — домашняя площадка (начало queue_key) — прежние поля; другая — исполнитель из dex_wallet_exec (Wallet.chains) и ключ очереди «<площадка>:<id>»; wallet_at, wallets_at, with_wallet_at, set_executor_at, set_executor_version_at |
| `edit_version.rs` | Решение 272: версия исполнителя кошелька («v1» / «v2», `dex_wallets.executor_version`) и обёртка из хранилища v2 (`executor_wrapped`, ревью 272 А1) — пишет адаптер DEX после сверки кода (onchain.rs), только для сверенного адреса; запись — только журнал, без сигнала «кошельки изменились» (ревью Б1: подписки кошельков не перезапускаются); смена адреса (edit.rs) — сброс |
| `migrate.rs` | Перенос старого кошелька `bsc_dex.wallet_key` один раз: кошелёк «BingX», исполнитель из старой настройки, строки биржи и `probe` |
