# settings — хранилище настроек

| Файл | Что делает |
| --- | --- |
| `schema.rs` | Описание настройки: тип, ограничение, единица, области |
| `catalog/` | Список всех настроек — зеркало `docs/SETTINGS.md`, по частям (README внутри). Значений нет |
| `scope.rs` | Область значения: система / площадка / монета / событие / DEX / канал отправки |
| `value.rs` | Проверка значения: тип, ограничение, варианты выбора, верхняя граница, адрес BSC |
| `store.rs` | SQLite + копия в памяти, история изменений, рассылка изменений |
| `live.rs` | Подписка компонента на изменения своих настроек — без перезапуска |
| `read.rs` | Типизированное чтение с подстановкой (монета → площадка → система); не задано → `NotConfigured` |
| `read_scope.rs` | Типизированное чтение ровно в области (DEX, канал, событие) и адресов BSC |
| `wait.rs` | Цикл, которому нужна настройка, ждёт её задания и продолжает сам (until_ok, одна запись «ждёт», одна «снова работает»; решение 75) |

Значений по умолчанию нет. Действует самое узкое заданное значение: монета → площадка → система.
Области «событие», «DEX» и «канал» — без подстановки: значение ровно для своего id.
