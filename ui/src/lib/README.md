# ui/src/lib — общий код интерфейса

| Файл | Что делает |
| --- | --- |
| `api.js` | Запросы к REST; ошибка бэкенда → Error с его текстом |
| `live.svelte.js` | Одно WebSocket-подключение к `/api/ws`, рассылка сообщений; переподключение по событиям браузера |
| `settings.svelte.js` | Схема, значения настроек и площадки; обновление из живого потока; изменение значения |
| `secrets.svelte.js` | Состояние секретов и список известных (без значений) |
| `router.svelte.js` | Навигация по адресу `#/экран/аргумент` |
| `prefs.js` | Удобства зрителя в браузере (размер страницы); не секреты |
| `labels.js` | Русские подписи вариантов типов бэкенда, показ значений и времени |
| `dex.svelte.js` | Списки адаптера DEX по площадкам: виды пулов и каналы — id областей «DEX» и «канал» |
| `remote.svelte.js` | Данные экрана из одного GET: 503 → «нет данных», перечитывание по живым сообщениям |
| `coinLabels.js` | Показ проверок монет и пулов: налоги, причины чёрного списка, группы крючков |
| `control.svelte.js` | Режим системы и команды управления (GET/POST /api/control, живое сообщение control) |
| `coreLabels.js` | Подписи данных ядра: режим, состояние направления, шаг сделки, направление строкой |
