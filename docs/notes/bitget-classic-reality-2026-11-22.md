# Bitget Classic и токенизированные акции, 22.11.2026

В выборке журнала работающего бота за 13:12:09–13:13:45 UTC ошибки Bitget `40502` относились к 430 разным тикерам. У всех 430 публичный каталог SPOT v3 указывал `isReality=yes`. Например, у `RROLUSDT` каталог Classic v2 показывал `baseCoin=rROL`, `status=online`, а запрос Classic orderbook вернул `40502`. Тикер `RWA` относится к обычному споту. Классификацию даёт поле биржи, регистр или префикс тикера для этого непригодны.

При сверке полных публичных каталогов на дату проверки у 498 из 3 596 пар Classic с `quoteCoin=USDT` v3 указывал `isReality=no`, у 3 098 — `yes`. Контрольные запросы Classic для CAKEUSDT, RWAUSDT и RENDERUSDT вернули пять уровней на каждой стороне. Все числа относятся к этому снимку. [Пары Classic](https://api.bitget.com/api/v2/spot/public/symbols) · [Пары SPOT v3](https://api.bitget.com/api/v3/market/instruments?category=SPOT)

У 3 097 пар Reality справочник кошельков показывал ввод и вывод в Arbitrum One. В снимке `arb_dex/pool-directory` бота по совпадению контрактов нашлось семь уникальных пулов, в том числе шесть со статусом `Taken`. Эти данные подтверждают наличие DEX-стороны, но для оценки упущенной прибыли потребовались бы синхронная глубина, комиссии и стоимость исполнения. [Сети Bitget](https://api.bitget.com/api/v2/spot/public/coins)

Текущий торговый адаптер использует Classic v2 для размещения, отмены и восстановления ордера. У Reality в часы торгов акциями США стандартный стакан v3 возвращает один уровень, для объединённой глубины нужен отдельный допуск. Для ордеров нужен UTA. Для допуска в торговлю предстоит проверить действие IOC/FOK, исход при тайм-ауте, комиссии и сверку баланса на соответствующем типе счёта. [Руководство Bitget](https://www.bitget.com/docs/uta/reality-trading-guide) · [Ордера UTA](https://www.bitget.com/docs/catalog/trading/order-management)

Четыре строки каждого публичного каталога сохранены с полями биржи и временем ответа. Для проверки отказа тест удаляет поле у одной строки. Явное `yes` другой строки отзывает книгу и допуск Classic на том же обновлении. При полном отказе каталога действует срок предыдущего снимка. При успешном восстановлении обычная пара возвращается в подписку. Сторож и соединение используют тот же состав, включая переподключение после отказа настройки.
