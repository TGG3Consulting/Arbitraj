# settings — хранилище настроек

| Файл | Что делает |
| --- | --- |
| `schema.rs` | Описание настройки: тип, ограничение, единица, области |
| `catalog.rs` | Список всех настроек — зеркало `docs/SETTINGS.md`. Значений нет |
| `value.rs` | Область значения (система / площадка / монета / событие) и проверка значения |
| `store.rs` | SQLite + копия в памяти, история изменений, рассылка изменений |
| `live.rs` | Подписка компонента на изменения своих настроек — без перезапуска |
| `read.rs` | Типизированное чтение; не задано → ошибка `NotConfigured` |

Значений по умолчанию нет. Действует самое узкое заданное значение: монета → площадка → система.
