## Что сделано сейчас (ui/, Svelte 5 + Vite)

Запуск и откуда данные — `ui/README.md`. Экран — файл в `ui/src/pages/`, общие элементы — `ui/src/components/`.
На всех экранах: плашка «Система заблокирована», пока секреты не разблокированы; плашка «Нет живой связи», пока нет WebSocket.
Изменения из других вкладок видны сразу (`/api/ws`). Ошибки бэкенда показываются как есть. Значений по умолчанию нет.

  сделки, начатые в периоде). Больше 50 МБ (предел Telegram для ботов) или сбой — причина в чат и журнал. Денег не
  двигает — без «Да, …».
- **Состояние** — режим и причина, итог дня (вся система и по площадкам, решение 173), паузы площадок и циклов,
  карантин; кнопки «Старт» / «Пауза» / «Стоп» (доступные — как на плашке), «Снять паузу <площадка>», «Снять паузу циклов
  DEX ↔ DEX», «Снять карантин <монета>», «Сбросить лимит дня (все)», «Сбросить лимит дня <площадка>», «Обновить». Каждая —
  с вопросом «Да, …». Обновляется сам (лайв).
- **Балансы** — список бирж и кошельков DEX → по бирже: каждый счёт (торговый помечен), монеты со свободным и в ордерах,
  у монеты «Продать <монета> (<счёт>)» (недоступная — причина в строке и по нажатию) → «Да, продать N <монета> со счёта …
  на <биржа>» → итог продажи «Выполнено: …»; по кошельку — BNB и USDT. «Обновить». Обновляется сам (лайв).
- **Перевести USDT** — шаг 1 «Откуда» (площадки со свободными USDT, с остатком), шаг 2 «Куда» (кроме «откуда»; от кошелька —
  только биржи), шаг 3 «Сколько» (можно вывести, удержания, комиссия и минимум вывода; «Всё», доли `notify.transfer_pct`,
  «Ввести сумму» — ответом на сообщение бота числом), шаг 4 — сводка «С X на Y: N USDT, комиссия вывода F, дойдёт N − F,
  сеть BSC», «Отправить» / «Отмена» → «Да, перевести USDT» → ход в том же сообщении: «проверка → отправлено → в сети
  (транзакция) → зачислено …» или причина.
- **Ручное управление** — сколько записей ждут (по видам) и «Открыть в чате «Неудачные»» (ссылка на последнее сообщение,
  если чат — супергруппа).

Лайв: правка не чаще `notify.live_refresh_s`, только если изменилось, пока были нажатия в последние `notify.live_idle_s`;
потом — «⏸ Экран заморожен — нажмите «Обновить»». Живой — только последний открытый экран чата. Денежные кнопки старше
`notify.dialog_ttl_s`, перерисованные или из прошлого запуска — «Экран устарел — откройте меню».
