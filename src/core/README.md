# core — ядро

Ничего не знает о конкретных площадках. Работает только со своими типами (`types/`) и со шлюзом.
Никогда не импортирует `venues/`. Карта и поток тика — ARCHITECTURE.md.

| Файл | Что делает |
| --- | --- |
| `types/` | Общие типы (стык, меняется только через запрос на изменение стыка) |
| `mod.rs` | Список модулей ядра |
| `deps.rs` | Зависимости ядра (шлюз, настройки, журнал, уведомления, база) и помощники журнала/уведомлений |
| `engine.rs` | `Core`: общее состояние и запуск фоновых задач; чтение состояния для api |
| `wait.rs` | Паузы фоновых задач по настройке; не задана — запись в журнал и ожидание, пока зададут |
| `market_state.rs` | Стаканы, пулы, проверки монет и крючков, каналы отправки — из событий адаптеров |
| `registry.rs` | Справочник: первичный фильтр монет и направлений с причинами отсева |
| `presence.rs` | Есть ли монета на площадке и в какой роли (биржа: сеть BSC, ввод/вывод, стакан; DEX: пул с USDT) |
| `registry_sync.rs` | Обновление справочника сетей бирж (coin_networks) и уведомление об открытии/закрытии ввода и вывода |
| `rebuild.rs` | Пересборка справочника и чёрного списка по «толчку»; уведомления о чёрном списке и исключённых пулах |
| `rebuild_report.rs` | Уведомления пересборки: чёрный список, итог проверки налогов, исключённые пулы |
| `blacklist.rs` | Чёрный список (ручной, проверка налогов, налог выше порога) и допуск пулов с крючками V4 |
| `subscribe.rs` | Подписки площадок на рыночные данные по справочнику |
| `tick.rs` | Поток тика: событие → состояние рынка → пересчёт направлений монеты → сигнал |
| `prices.rs` | Цены направления для грубого спреда — котировки шлюза на объём сравнения |
| `signal.rs` | Грубый спред, порог (процентные комиссии) и фильтр шума |
| `view.rs` | Живой поток ядра для интерфейса (`{"type","data"}`) |
| `coins_view.rs` | Данные экрана «Монеты и направления» (формат GET /api/coins) |
