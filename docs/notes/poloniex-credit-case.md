# Зачисление Poloniex, 23 ноября 2026

В журнале развёрнутой версии `cc1b4ef0` строка 9417247 содержит USDT +70.5413350700 и `eventType=DEPOSIT`. Адаптер сопоставлял только `deposit`, поэтому положительная дельта проходила в ядро как прочее изменение. Документация перечисляет семь значений в нижнем регистре. Адаптер сравнивает известные типы без учёта регистра и сохраняет имя из сообщения в журнале. [Данные журнала](../../tests/data/poloniex_deposit_2026-11-23/journal.json) · [Канал balances](https://api-docs.poloniex.com/spot/websocket/balance)

Уведомление биржи не содержит сеть, контракт или хеш. На одном счёте ожидаемые переводы одного биржевого тикера могут иметь разные контракты в разных сетях. Если одновременно есть такие билеты, ядро будит опрос каждого и ждёт его депозит по хешу. При однозначном совпадении продолжают действовать настройки допуска суммы и закрытия по событию. После закрытия по WS опрос работает как фоновое подтверждение. После закрытия по REST поздний WS участвует только в сверке.

Тесты используют сохранённый выход адаптера и официальный пример для проверки версии и нулевой дельты. Сырого кадра, его версии, состояния баланса до события и назначения перевода в записи журнала нет. Однократное закрытие по WS, поздняя сверка после REST и два одновременных ожидания разных сетей воспроизводятся как отдельные сценарии. Для одиночного ожидания другой сети, которому не подходит определённый справочником контракт, остаётся подтверждение по хешу. Ускорение реальных переводов можно оценить по новым событиям после установки.
