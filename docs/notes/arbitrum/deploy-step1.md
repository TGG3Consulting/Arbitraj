# Выкладка шага 1 двух сетей (решение 416, ветка feat/arbitrum) — порядок

Шаг 1 добавил три обязательные настройки площадки DEX. Без них после выкладки площадка DEX не подписывается на рынок,
не котирует и не подписывает транзакции. Монета получила поле сети (в JSON — только если указана, старые записи
читаются как раньше), ключ монеты на счёте биржи — из учёта ядра (core_state, вид coin_account).

## Порядок

1. «Стоп» (новых сделок нет).
2. Дождаться закрытия всех сделок и всех возвратов USDT (экран «Сделки»: открытых нет; перегоны USDT завершены).
   Так ни одна сделка не переживает смену ключей и настроек посреди жизни.
3. Выкладка сборки.
4. Задать у площадки bsc_dex (экран «Настройки» → группа «DEX» или карточка площадки bsc_dex):
   - `dex.chain` = `bsc`
   - `dex.evm_chain_id` = `56`
   - `dex.gas_ticker` = `BNB`
5. «Проверить подключение» площадки DEX: часть «Сеть площадки: bsc, chainId 56», узлы — «сеть 56», без ошибок.
6. «Старт».

## Если пропустить шаг 4

- Подписки DEX на рынок нет: журнал core.subscribe «Подписка не удалась: Не задана настройка dex.chain …»
  (или dex.evm_chain_id); котировок DEX нет — «Не задана настройка dex.gas_ticker».
- Предпроверка газа на DEX — отказ с той же причиной; балансы кошелька DEX — ошибка с причиной.
- Ничего не ломается в учёте: задать настройки — подписка повторится при изменении настроек.
