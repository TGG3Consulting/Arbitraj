# ui/src/pages — экраны (один файл — один экран)

| Файл | Экран |
| --- | --- |
| `Unlock.svelte` | Разблокировка: создание файла секретов, разблокировка, блокировка, секреты, смена пароля |
| `Venues.svelte` | Площадки: проверка подключения, ключи площадки, её настройки области Venue; у DEX — виды пулов и каналы; ключи площадок, которых ещё нет в шлюзе |
| `Settings.svelte` | Настройки по категориям (`#/settings/<категория>`): список категорий со счётчиками, поиск во всех категориях, «только незаданные» в категории или во всех, значения по областям, история |
| `Rules.svelte` | Правила шлюза: список, создание, изменение, выключение |
| `Notifications.svelte` | Уведомления: Telegram, события (вкл/выкл, площадки, условие) |
| `Journal.svelte` | Журнал: листание, фильтры, живые записи |
| `Coins.svelte` | Монеты (во всю ширину): ручной чёрный список, компактный список с фильтрами, окно монеты — налоги, пулы и крючки, чёрный список с причинами, «Перепроверить» |
| `Manual.svelte` | Ручное управление: алерты застрявших монет, «Беру на себя», «Вернуть боту» |
| `Channels.svelte` | Каналы отправки: настройки, ключ, проверка, состояние и статистика |
| `GasStats.svelte` | Статистика газа по монетам |
| `Live.svelte` | Живой экран (во всю ширину): плашка режима (сухой / обычный, решение 74); компактная строка на монету, спред и порог в обе стороны по каждой паре площадок (решение 55), короткое состояние; окно монеты с ценами и причинами; кандидаты с причинами отказа, полным расчётом и карточкой сигнала (решение 74) |
| `Deals.svelte` | Сделки: шаг, где монеты, вложено/выручка/затраты, итог против плана, хронология и план |
| `Episodes.svelte` | Эпизоды арбитражной ситуации (решение 74): список (монета, направление, сухой, начало, длительность, макс. прибыль, причина закрытия), просмотр, «Скачать» |
