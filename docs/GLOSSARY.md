# GLOSSARY — словарь проекта

> Эти слова в коде, комментариях, интерфейсе и документах означают ровно это. Новые термины — сюда.

| Термин | Значение |
| --- | --- |
| Площадка (venue) | Место, где покупаем или продаём: биржа (BingX) или DEX в сети BSC |
| Биржа (CEX) | Централизованная биржа со стаканом и аккаунтом: BingX, позже Gate, MEXC |
| DEX | Децентрализованная биржа в блокчейне: смарт-контракт с пулами, без стакана и аккаунта (PancakeSwap, Uniswap и др.) |
| Пул | Контракт DEX, в котором лежат две монеты (например X и USDT); цена = их соотношение |
| Пул V2 | Классический пул: цена считается из двух остатков монет |
| Пул V3 | Пул с концентрированной ликвидностью: ликвидность распределена по ценовым диапазонам |
| Кошелёк | Наш адрес в сети BSC; один приватный ключ для всех DEX |
| Разрешение (approve) | Разовая транзакция, дающая контракту DEX право забирать монету с нашего кошелька |
| Газ | Плата сети BSC за каждую транзакцию, платится в BNB |
| Налог токена | Процент, который токен удерживает при переводе или обмене |
| Направление | «Монета, купить на A, продать на B». У монеты при N площадках N×(N−1) направлений |
| A / B | Роли в направлении: A — где покупаем, B — где продаём |
| Справочник | Список монет и направлений, прошедших первичный фильтр (шаг 1) |
| Тик | Одно обновление цены, стакана или пула на любой площадке |
| Грубый спред | (лучший bid на B − лучший ask на A) / лучший ask на A — быстрая проверка на каждый тик |
| Кандидат | Направление, прошедшее грубый спред и фильтры шума; идёт в полный расчёт |
| Котировка на объём | Сколько заплатим или получим за Q монет с учётом ликвидности |
| Проскальзывание | Ухудшение средней цены с ростом объёма (по стакану или по пулу) |
| Время в пути (T) | Время от вывода с A до зачисления на B |
| Запас r | Заложенное в расчёт изменение цены на B за время в пути |
| Коэффициент h | Доля глубины стакана или пула B, которую разрешено использовать |
| Ядро (core) | Логика системы; не знает о конкретных площадках |
| Шлюз (gateway) | Единая точка входа для ядра: контракт, маршрутизация, правила, единые ошибки и события |
| Адаптер | Изолированный модуль площадки: свой REST, WebSocket, разбор, ошибки |
| Контракт адаптера | Набор функций, обязательный для каждого адаптера (ARCHITECTURE.md) |
| Правило шлюза | Событие + условие + действие + область (все площадки или одна) |
| Карантин | Направление или монета временно исключены из торговли до ручного решения или истечения времени |
| Стоп-условие | Событие, при котором система сама прекращает новые сделки |
| Устаревшая цена | Цена без обновлений дольше допустимого или с разорванным соединением; по ней сигналов нет |
| Хранилище настроек | SQLite с историей; единственный источник всех параметров системы |
