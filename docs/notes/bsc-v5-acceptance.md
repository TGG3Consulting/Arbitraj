# Допуск V5 в BSC

В сборке cc1b4ef0 запись для исполняемого кода V5 была только в Arbitrum. BSC имела собственную запись для V3. Проверка deploy использует пару версии и chainId, поэтому отказ для BSC был штатным.

23 ноября 2026 года со штатной BSC-ноды снята отдельная запись V5 на блоке 135328859. Кандидатами послужили шесть известных пулов двух классов. У одного пула каждого класса квотер не дал подобрать размер до симуляции. На остальных четырёх получены восемь успешных вызовов: по покупке и продаже на каждом пуле. Выход исполнителя совпал с квотером в том же состоянии и с суммой из события Swap. После каждого вызова остатки обоих токенов на адресе исполнителя равны нулю.

Запись покрывает Uniswap V4 и PancakeSwap Infinity CL без крючков. Штатные правила допуска пары версия/сеть и маршрута каждого класса применяются к записи без изменений. Деплой в основной сети при записи и проверке не выполнялся.

При добавлении кошелька карточка каждой сети показывает классы версии, доступной для развёртывания. Первая кнопка получает оценку через GET. При подтверждении передаются выбранные при оценке кошелёк, площадка и прежний адрес исполнителя. Для сверенных V4 и V5 экран отдельно проверяет совпадение обёртки нативной монеты сети.
