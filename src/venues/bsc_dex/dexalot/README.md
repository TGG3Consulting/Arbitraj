# Dexalot Simple Swap

Кнопка проверки ключа вызывает POST /api/venues/{id}/dexalot/check-key без тела. Модуль channel.rs проверяет физическую сеть Base и читает закрытый список цен через GET /prices?chainid=8453. Подпись кошелька и резервирование ликвидности для этого чтения не нужны. Ключ берётся из зашифрованного хранилища. Клиент сверяет адрес с рекомендацией, встроенной в сборку, запрещает переходы по перенаправлениям и очищает сообщения об ошибках. [Документация Dexalot, раздел 3b](https://github.com/Dexalot/dexalot-docs/blob/a2a1ec62007cc2513a9099a8cec59a7da5487712/docs/en/apiv2/SimpleSwap.md#3b-request-batched-quotes-optional)

| Модули | Назначение |
|---|---|
| price, automatic_feed, automatic | Публичная цена, хранение наблюдений и выбор момента запроса firm |
| firm, firm_option, wire | Бюджет владельца, подписанная заявка и симуляция допустимых вариантов платежа |
| profile, profile_order | Привязки router, maker и модуля, проверка nonce и подписи на блоке |
| routing_book, routing | Заявки кошелька и выбор по чистому результату с газом |
| trade, receipt | Отправка выбранного варианта и подтверждение выплаты |
