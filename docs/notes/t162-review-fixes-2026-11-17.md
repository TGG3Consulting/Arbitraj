| Н1 | Фикс вывода A < 0 без поправки по фактам — метод не действует (assemble — ошибка «inputs», кандидат в полный расчёт). ## Сколько из 18 отсекает живой код

tests/core_sieve_recorded_t162.rs собирает границу настоящим assemble (κ — из k·σ·√T контекста, ставки — fee_of по
котировкам записи). Стаканов и пулов в записи нет — ρ и лучший уровень = средние записи, k выведен из запаса записи.
Тест утверждает: отсечено 17 из 18 (NXT — нет). Это ВЕРХ того, что отсечёт живой код на тех же моментах (настоящий ρ ≥
средней, лучший уровень не хуже средней, k записи ≥ живого при доле закрытия) — прогнозом не является; точное число
по 18 случаям без записей стаканов и пулов на момент расчёта не выводится.
