# ui/src/components — общие элементы экранов

| Файл | Что делает |
| --- | --- |
| `CheckConnection.svelte` | Кнопка «Проверить подключение»: «Подключено …» зелёным или причина сбоя красным |
| `DexDrySwap.svelte` | «Сухая сделка DEX» (решение 121, C4) на «Ручном управлении»: монета, сторона, сумма USDT, режим (как сделка / через исполнитель ArbExecutor с подставленным кодом — решение 122), «Проверить своп» → POST /api/dex/dry-swap; итог таблицей (форма, пулы, выходы, минимум, газ, причина) |
| `DexDryCycle.svelte` | «Сухая сделка DEX» → режим «цикл DEX ↔ DEX» (решение 124): «Загрузить циклы», выбор цикла, свой бюджет USDT, режим (как сделка / через исполнитель), «Проверить цикл» → POST /api/dex/dry-cycle |
| `DryResult.svelte` | Итог сухой сделки таблицей — общий для свопа и цикла (решения 121 C4, 124) |
| `ExecutorDeploy.svelte` | Решения 122 X и 132: исполнитель ArbExecutor кошелька DEX (на «Маппинге кошельков», `?wallet=<id>`): «Развернуть исполнитель» (оценка → окно подтверждения → отправка с этого кошелька), «Проверить подключение» исполнителя; код в сети совпал — адрес записан у кошелька |
| `ErrorText.svelte` | Текст ошибки бэкенда как есть, красным |
| `LockBanner.svelte` | Плашка «Система заблокирована» на всех экранах |
| `LiveBanner.svelte` | Плашка «Нет живой связи с сервером» и кнопка «Переподключиться» |
| `PageSize.svelte` | Поле «сколько записей показывать» (без значения по умолчанию, запоминается в браузере) |
| `SettingEditor.svelte` | Значение одной настройки в одной области: показ, ввод, «Сохранить», «Очистить» |
| `SettingCard.svelte` | Карточка настройки на экране «Настройки»: описание и значения по всем областям |
| `SettingHistory.svelte` | История изменений одной настройки |
| `SecretRow.svelte` | Один секрет: введён ли, ввод значения с паролем, удаление |
| `RuleForm.svelte` | Форма создания и изменения правила шлюза |
| `DexFamilies.svelte` | Таблица сопоставления «DEX индексатора → вид пулов» (решение 58): вид, включатель, адреса и настройки DEX (область «DEX»), итог по пулам справочника, перенос настроек из другой строки |
| `PoolDirectory.svelte` | Блок «Справочник пулов (индексатор)» площадки DEX (решение 58): источник, ошибки, монеты, итог по пулам, DEX индексатора; монеты, пулов которых индексатор не знает (404, решение 121), и поиск по фабрикам на своём узле (index.factory_scan: вызовов, найдено, взято) |
| `CoinDirectory.svelte` | В окне монеты: пулы из справочника индексатора и итог бота по каждому |
| `Attribution.svelte` | Подпись источника данных (index.attribution_text / _url), если задана |
| `VenueChannels.svelte` | Блок «Каналы отправки» площадки DEX: ключ канала и «Проверить подключение» |
| `NoData.svelte` | Плашка «нет данных» с причиной бэкенда (не путать с пустым списком) |
| `CoinRow.svelte` | Полная карточка монеты (во всплывающем окне): налоги, чёрный список, причины по площадкам и пулам — по строке, пулы с крючками, «Перепроверить» |
| `PoolDepthCell.svelte` | «Монеты», окно монеты: глубина пула по направлениям в полосе цены, глубокий / мелкий, спит ли, сверка с квотером, tickSpacing (решение 73) |
| `CoinTable.svelte` | «Монеты»: компактный список — тикер, адрес коротко, итог отбора, налоги коротко, пулы (допущено / всего); щелчок — окно |
| `CoinFilters.svelte` | «Монеты»: фильтры — поиск по тикеру/адресу, итог отбора, площадка, есть/нет пулов, вид пула, налоги, только чёрный список |
| `CoinModal.svelte` | «Монеты»: всплывающее окно монеты — адрес с «Копировать», итог отбора, полная карточка (CoinRow) |
| `Modal.svelte` | Всплывающее окно с крестиком; закрытие по Esc и щелчку мимо окна |
| `CopyAddr.svelte` | Полный адрес контракта и кнопка «Копировать» |
| `ManualBlacklist.svelte` | Ручной чёрный список монет: добавить с причиной, убрать |
| `ChannelCard.svelte` | Один канал отправки: статистика, настройки, ключ, проверка |
| `ControlBar.svelte` | Плашка режима системы на всех экранах: «Старт», «Пауза», «Стоп», паузы площадок и карантины монет |
| `LiveCoins.svelte` | «Живой экран»: компактная таблица «одна строка — одна монета» без переносов, колонки — каждая пара площадок из данных в обе стороны (решение 55); щелчок — окно |
| `LiveCoinModal.svelte` | «Живой экран»: всплывающее окно монеты — адрес с «Копировать», по направлениям точные цены, спред, порог, состояние и причины по строкам |
| `SpreadCell.svelte` | Одно направление монеты в строке: спред % и порог % (3 знака), короткое состояние со значком; нет данных — «—» с причиной в подсказке |
| `CalcTiming.svelte` | Время расчёта кандидата по этапам и частям (решение 129): мс, сколько раз, запросы к узлу и агрегатору; этап, на котором стоял отказ по сроку, — «идёт» |
| `CostLines.svelte` | Затраты расчёта кандидата по шагам маршрута (решение 52): в цене / в количестве / вычитается |
| `WalletQueue.svelte` | Очередь кошелька DEX (своя у каждого кошелька, решение 132; на «Каналах отправки» — по кошелькам): состояние и «Снять очередь после ручной проверки» (второе подтверждение при незанятом nonce) |
| `WalletList.svelte`, `WalletRow.svelte`, `WalletMap.svelte` | Решение 132, экран «Маппинг кошельков»: добавить кошелёк (имя + ключ), карточка кошелька (адрес, BNB/USDT, исполнитель, проверка, переименовать, удалить), маппинг строк → кошелёк с предупреждением «деньги смешиваются» и историей |
| `NavMenu.svelte` | Верхнее меню: ссылки экранов, «Настройки ▾» по категориям со счётчиками, редкие экраны в «Ещё ▾» |
| `NavDropdown.svelte` | Пункт меню с выпадающим списком ссылок; закрытие выбором, Esc, щелчком мимо |
| `SettingsGroupList.svelte` | «Настройки»: боковой список категорий со счётчиками, ссылки `#/settings/<категория>` |
| `DryBanner.svelte` | Плашка сухого режима (решение 74): в шапке — когда включён; на «Живом экране» — всегда (сухой / обычный / не задан) |
| `SignalCard.svelte` | Карточка сигнала (решение 74): монета и контракт, где купить и продать, стакан и пулы в полосе, максимальный объём и прибыль без бюджета, ссылки |
| `UncappedLine.svelte` | Строка «без потолка: вложить X → прибыль Y; плюс от Z; упущено; ограничило» (решение 141) |
| `UncappedRecord.svelte` | Подробности записи «без потолка»: бой и бюджет, оптимум, таблица потолков, состав затрат (решение 141) |
| `DealUncapped.svelte` | В карточке сделки: «зашли на X → потенциал без потолка; потенциал − факт» (решение 141) |
| `DexCycles.svelte` | «Живой экран»: сигналы циклов DEX ↔ DEX (решение 85) по площадкам-DEX — базовая монета, вложено и чистая прибыль, затраты, маршрут по шагам, флаг «исполнимо / сигнал» и причина; кнопка «Обновить» |
| `EpisodeView.svelte` | Окно эпизода (решение 74): записи пересчётов, карточка и стаканы выбранной записи, «Скачать файл» |
| `EpisodeReplay.svelte` | Плеер офлайн-реплея записанного эпизода (решение 74): таймлайн-ползунок, play/пауза, шаг, скорость; синхронно кадру — стаканы, пулы, прибыль и карточка; мини-график прибыли. Подписано: воспроизведение записанных данных, не пересимуляция |
| `DepthStepper.svelte` | Стакан всей глубины на странице окна (решение 125, дополнение): шаг по кадрам изменений, стакан после кадра (полный + изменения), что сделано с кадром, версия |
| `WindowView.svelte` | Страница окна (решение 125): каналы по биржам, стакан по времени (шаг по кадрам, уровни на момент кадра, время биржи и получения), лента сделок с событиями нашей сделки на одной шкале, порции кадров offset/limit, «Скачать файл» |
| `ProfitSparkline.svelte` | Мини-график прибыли по записям эпизода (inline-SVG, без библиотек): линия, нулевая ось, отметка текущей записи |
