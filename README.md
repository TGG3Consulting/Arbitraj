# ARB — спотовый арбитраж BingX ↔ DEX в сети BSC

Система покупает монету там, где она дешевле, переводит по сети BSC и продаёт там, где дороже — только если прибыль после всех затрат выше порога.
Первый этап: биржа BingX ↔ DEX в сети BSC (PancakeSwap, Uniswap) через свой кошелёк. Дальше — Gate, MEXC и другие.

## Сборка и запуск

### Windows (ПК Тиграна) — готовая сборка
1. GitHub → репозиторий → **Actions** → **Windows build** → последний зелёный запуск → внизу **Artifacts** → скачать `arb-windows`.
2. Распаковать в постоянную папку, например `G:\ARB-run` (не в «Загрузки»). Папка `data` с настройками и зашифрованными ключами появится рядом при первом запуске — её не удалять и не отдавать.
3. Запустить `start.bat`. Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае» (файл не подписан сертификатом).
4. Открыть в браузере `http://127.0.0.1:8787`. Окно `start.bat` не закрывать — это и есть работающая система; закрыли окно — система остановлена.
5. Обновление: скачать новый `arb-windows`, остановить систему (закрыть окно), заменить `arb.exe` и папку `ui`, папку `data` не трогать, снова `start.bat`.

### Сборка из исходников (разработчику)
- Нужно: Rust stable (`rustup`), Node.js 22.
- `cargo build --release` и `cd ui && npm ci && npm run build`.
- Запуск: `arb --data-dir <папка данных> --listen 127.0.0.1:<порт> --live-buffer <N> --ui-dir ui/dist` (аргументы — `src/cli.rs`).
- Веб-сервер — только на 127.0.0.1, пока не решён вопрос авторизации (ARCHITECTURE.md, «Открытые вопросы»).
