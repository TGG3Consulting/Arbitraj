# ui/src — код интерфейса

| Файл / папка | Что делает |
| --- | --- |
| `main.js` | Точка входа: стили и монтирование `App.svelte` |
| `App.svelte` | Меню экранов, плашки, выбор экрана по адресу `#/экран`; запуск живого потока и хранилищ |
| `app.css` | Общие стили, светлая и тёмная тема по настройке системы |
| `pages/` | Экраны — один файл на экран |
| `components/` | Общие элементы экранов |
| `lib/` | Запросы к API, живой поток, общие хранилища, навигация |
