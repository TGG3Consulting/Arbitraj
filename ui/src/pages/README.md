# ui/src/pages — экраны (один файл — один экран)

| Файл | Экран |
| --- | --- |
| `Unlock.svelte` | Разблокировка: создание файла секретов, разблокировка, блокировка, секреты, смена пароля |
| `Venues.svelte` | Площадки: проверка подключения, ключи площадки, её настройки области Venue; у DEX — виды пулов и каналы; ключи площадок, которых ещё нет в шлюзе |
| `Settings.svelte` | Настройки: все параметры по группам, значения по областям, история |
| `Rules.svelte` | Правила шлюза: список, создание, изменение, выключение |
| `Notifications.svelte` | Уведомления: Telegram, события (вкл/выкл, площадки, условие) |
| `Journal.svelte` | Журнал: листание, фильтры, живые записи |
| `Coins.svelte` | Монеты: налоги, пулы и крючки, чёрный список с причинами, «Перепроверить», ручной чёрный список |
| `Manual.svelte` | Ручное управление: алерты застрявших монет, «Беру на себя», «Вернуть боту» |
| `Channels.svelte` | Каналы отправки: настройки, ключ, проверка, состояние и статистика |
| `GasStats.svelte` | Статистика газа по монетам |
| `Live.svelte` | Живой экран: одна строка на монету, спред в обе стороны по каждой паре площадок (решение 55), состояние фильтра шума, кандидаты с причинами отказа и полным расчётом |
| `Deals.svelte` | Сделки: шаг, где монеты, вложено/выручка/затраты, итог против плана, хронология и план |
