# settings/accounts — кошельки DEX и маппинг (решение 132)

Кошелёк — «счёт» внутри одной площадки DEX. Ключ лежит в зашифрованном файле секретов (docs/SECURITY.md);
здесь — только имя секрета. Доступ — `Store::accounts()`.

| Файл | Что делает |
| --- | --- |
| `mod.rs` | Типы (`Wallet`), строки `dex_dex` и `probe`, чтение: кошельки, строки маппинга, кошелёк переноса, «деньги смешиваются» |
| `db.rs` | Загрузка из SQLite (`dex_wallets`, `dex_wallet_map`, `dex_wallet_meta`), история (`dex_wallet_history`) |
| `edit.rs` | Добавить, переименовать, задать исполнитель, удалить (запрещено, пока в маппинге или в незавершённой сделке; секрет не удаляется) |
| `edit_map.rs` | Привязка строки маппинга, новый id, общие помощники: история в одной транзакции, журнал `wallets.changed` |
| `migrate.rs` | Перенос старого кошелька `bsc_dex.wallet_key` один раз: кошелёк «BingX», исполнитель из старой настройки, строки биржи и `probe` |
