# Проверка возвращённого поля

Входом служат код getter, вызов `balanceOf` и ключ, который действительно прочитал узел для данного держателя. Модуль отслеживает, какое слово попало в возвращаемые 32 байта. Операции стека и памяти описаны в приложении H спецификации Ethereum. [Ethereum Yellow Paper](https://ethereum.github.io/yellowpaper/paper.pdf)

Для отдельного поля uintN маска getter задаёт максимальный баланс. Исходное слово сверяется с полным результатом balanceOf. Запрос симуляции на значение, которое шире поля, переходит к штатному пополнению. У XVS проверенная разрядность составляет 96 бит.
