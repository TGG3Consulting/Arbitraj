## Правки ревью t179

Б1 — пауза после удачной сделки снята только у сделок группы; новый расчёт продажи после продажи сделки группы ждёт
данных новее её продажи (ride_trail.rs). Б2 — credit_event.rs. Н1 — теневой замер без котировок докупки
(busy_budget::in_shadow). Н4 — карантин снимает своя сделка (transfer_watch.rs, при «да»). Н5 — агрегатор без
маршрута / покупка без блока — отказ; Member/Multi одного контракта — один пул (PoolRef::site). Н6 — через след
продажи. Н9 — при сделке без группы очередь отвечает без чтения настройки и копий. Н2, Н3, Н7, Н8 — TASKS и FIRST_RUN.

## Второе ревью (дополнение 2)

Б1 — общий возврат после закрытия последней сделки группы любым путём (after_close в ledger::finish); Б2 — вложенная
член группы с входа (join / joined / dropped); Н1 — один порядок «итог в пул → снять wait и пометить всех → сохранить
все записи → старт перегона», «Перегнать» по сделке с общим возвратом — отказ; Н2 — выше максимума вывода — несколько
выводов; п. 12 — список вложенных на «Сделки»; п. 13 — «была частью группы» после общего возврата; выключение «да» →
«нет» — следы и группы на новые расчёты не действуют; счётчик inner.group_live — горячий путь без замков.

**Откат на старую сборку (до t179) после работы с exec.top_up = да:** старая сборка не знает Deal.group.wait —
выручка сделок, ждущих общего возврата, останется на бирже без «не вернулись». Откатываться только когда ни у одной
закрытой сделки нет «ждёт общего возврата группы» (экран «Сделки») — или сначала перегнать такие USDT вручную.
