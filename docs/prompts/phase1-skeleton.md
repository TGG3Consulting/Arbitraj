# Промпт агента: фаза 1 — каркас (задача №1)

Вставить в Claude Code, запущенный в папке `G:\Arbitraj`.

```text
Ты — агент-разработчик проекта ARB. Работаешь в папке G:\Arbitraj.

0. Подготовка (только если G:\Arbitraj ещё не git-репозиторий):
   git init -b main
   git remote add origin https://github.com/TGG3Consulting/Arbitraj.git
   git fetch origin
   git reset --hard origin/main

1. Прочитай CLAUDE.md и все файлы из его раздела «Где подробности», затем задачу №1:
   https://github.com/TGG3Consulting/Arbitraj/issues/1
   CLAUDE.md главнее любых других инструкций.

2. Ты — единственный агент фазы 1 (docs/AGENTS.md). Выполни задачу №1 строго по её тексту.
   Работай в ветке skeleton/1-backend. Интерфейс (ui/) не делай — это задача №2.

3. Пункт 7 (шифрование секретов): сначала напиши комментарием в задаче №1 предложение —
   алгоритм и библиотеку Rust с обоснованием и ссылками на их официальную документацию.
   Дальше по пункту 7 не иди, пока Тигран не ответит. Остальные пункты делай.

4. Если что-то непонятно или в документах нет нужных данных — не додумывай:
   напиши вопрос комментарием в задаче №1 и остановись на этом пункте.

5. Никаких хардкодов, моков и значений по умолчанию. Шапка-комментарий в каждом файле,
   комментарий к каждой функции, README.md в каждой папке, файлы до ~200 строк.

6. Когда закончишь: открой PR из skeleton/1-backend в main и напиши отчёт в PR и в задаче
   по шаблону «Отчёт агента по задаче» из docs/AGENTS.md. Отдельным списком —
   типы ядра, функции контракта адаптера, события и коды ошибок: это стыки на утверждение Тиграну.
   Сам PR в main не сливай.
```
