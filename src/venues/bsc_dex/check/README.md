# venues/bsc_dex/check — проверки монет и пулов (решения 30, 32)

Пока проверка не завершена — торговли нет: котировка отвечает `CoinNotChecked` / `CoinCheckFailed`.

| Файл | Что делает |
| --- | --- |
| `state.rs` | Итоги в памяти: налоги монет, газ обмена по пулу, влияние крючка, сверка с квотером |
| `simulate.rs` | `eth_simulateV1`: цепочка вызовов в одном блоке без подписи (execution-apis) |
| `probe.rs`, `probe_calls.rs` | Пробный обмен в пуле V2/V3: налог покупки, продажи, перевода; газ покупки и продажи |
| `taxes.rs` | Проверка монеты: пробы по пулам V2/V3 (V2 впереди), источник USDT — другой пул реестра |
| `hooks_probe.rs` | Влияние крючка V4 группы B/C: квотер (исполняет крючок) против математики |
| `cycle.rs` | Циклы налогов (`tax.recheck_interval_s`) и крючков (`hooks.recheck_interval_s`), события CoinCheck / PoolCheck |
| `quoter_cycle.rs` | Цикл сверки с квотером (`dex.quoter_check_s`) |

Монета только с пулами V4 пока не проверяется (проба через Universal Router — шаг 1d) — CoinCheck «не прошла» с причиной.
