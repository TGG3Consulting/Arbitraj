# UI — экраны интерфейса

> Каждая фича обязана появиться здесь и в интерфейсе. Экран — один файл в `ui/src/pages/`.

| Экран | Что показывает | Чем управляет | Откуда данные |
| --- | --- | --- | --- |
| Площадки | Подключённые площадки, статус соединений, задержки, разрывы; у DEX — справочник пулов и таблица «DEX индексатора → вид пулов» с адресами (решение 58) | Включить или выключить площадку и DEX (dex.pool_enabled), вид DEX (dex.kind); режим обмена | api/venues.rs, api/check.rs ← gateway; статусы — api/stream.rs (позже) |
| Монеты и направления | Справочник, причина исключения монеты; налоги (покупка, продажа, перевод) и состояние проверки; пулы монеты с видом, крючком и группой A/B/C; чёрный список с причиной | Исключить или вернуть монету (ручной чёрный список coin.blocked), «Перепроверить», снять карантин | core/registry.rs, core/blacklist.rs; маршруты — src/api/README.md |
| Ручное управление | Алерты застрявших монет, монеты «Беру на себя» с причиной | «Продать сейчас», «Беру на себя», «Вернуть боту» | core/stuck.rs, core/manual.rs |
| Каналы отправки | Каналы DEX: состояние, отправлено, в блоке, откатов, газ впустую | Вкл/выкл, адрес, способ одиночная/бандл, минимальная цена газа, чаевые; ключ; «Проверить подключение» | адаптер DEX через шлюз (send_channels), core |
| Статистика газа | По монете: попытки, успехи, отмены, газ впустую и всего, итог | — | core/gas_stats.rs |
| Живой экран | Текущие спреды по направлениям, кандидаты, причины отказа; режим (сухой / обычный) и карточка сигнала (решение 74) | Фильтры отображения | core/signal.rs, core/candidates.rs, core/card.rs |
| Эпизоды | Эпизоды арбитражной ситуации (решение 74): монета, направление, начало, длительность, макс. прибыль, причина закрытия; записи эпизода | Просмотр, «Скачать» | core/episode_view.rs, storage/episode_files.rs |
| Разблокировка | Заблокированы ли секреты | Ввод пароля, добавление и замена секретов (docs/SECURITY.md) | settings/, хранилище секретов |
| Сделки | Идущие сделки по шагам (покупка, перевод, продажа), история, план против факта | Остановка сделки | core/executor.rs, core/ledger.rs |
| Балансы | BingX, кошелёк, монеты в пути, BNB на газ | — | core/ledger.rs |
| Настройки | Все параметры из settings/schema.rs, с описанием и допустимым диапазоном | Изменение на лету | settings/ |
| Правила шлюза | Общие правила и правила площадок | Создать, изменить, выключить правило; для «результат неизвестен» (OutcomeUnknown) действия «Повторить» нет (решение 64) | gateway/rules.rs |
| Управление | Состояние системы (плашка режима на всех экранах) | Старт, стоп, пауза системы; снятие паузы площадки и карантина монеты | core/risk.rs, core/commands.rs |
| Журнал | Ошибки, уведомления, история изменений настроек (кто, что, когда) | Фильтры | storage/, settings/ |
| Уведомления | Какие события уходят в Telegram | Вкл/выкл каждого события, площадки и условие события; токен бота и ID чата; кнопка «Проверить подключение» | notify/, settings/ |

Правила:
- Изменение в интерфейсе применяется сразу, без перезапуска, и пишется в журнал.
- Везде, где вводится ключ, токен или адрес подключения (биржа, кошелёк, узел BSC, Telegram), есть кнопка «Проверить подключение». Ответ — «Подключено» или точная причина сбоя: единый код ошибки + исходный текст ответа сервиса.

## Что сделано сейчас (ui/, Svelte 5 + Vite)

Запуск и откуда данные — `ui/README.md`. Экран — файл в `ui/src/pages/`, общие элементы — `ui/src/components/`.
На всех экранах: плашка «Система заблокирована», пока секреты не разблокированы; плашка «Нет живой связи», пока нет WebSocket.
Изменения из других вкладок видны сразу (`/api/ws`). Ошибки бэкенда показываются как есть. Значений по умолчанию нет.

| Экран | Что есть сейчас |
| --- | --- |
| Разблокировка | Создание файла (пароль + подтверждение), разблокировка, блокировка, известные секреты: введён ли, ввод значения с паролем, удаление; смена пароля. Переход к секрету по ссылке `#/unlock/<имя>` |
| Площадки | Площадки из реестра шлюза (`GET /api/venues`); по каждой: «Проверить подключение», её ключи (секреты с её scope), все её настройки области «площадка» по группам. Статусов соединений, задержек и разрывов пока нет — бэкенд их ещё не отдаёт; включение площадки — настройка `venue.enabled` |
| Настройки | По категориям — поле group схемы (своих категорий в интерфейсе нет). Пункт меню «Настройки» — выпадающий список: «Все категории и поиск» и каждая категория с числом настроек и числом не заданных нигде («DEX — 18, не задано 6»). Категория открывается по адресу `#/settings/<категория>` (можно сохранить ссылку, «Назад» браузера работает); слева — список категорий со счётчиками для переключения без меню (на узком экране — над настройками). Поиск по имени и описанию — всегда во всех категориях, результаты по категориям; «только незаданные нигде» — в открытой категории или во всех (переключатель). Карточка: описание, единица, вид, ограничение, области; значения: вся система, каждая площадка, монеты (ввод тикера), события (выбор кода); «Очистить»; история |
| Меню | В одну строку при ширине от 1024 px: Разблокировка, Площадки, Живой экран, Сделки, Монеты, Ручное управление, Настройки ▾, Журнал, Ещё ▾. В «Ещё» — редкие экраны: Каналы отправки, Статистика газа, Правила шлюза, Уведомления (флаг more у экрана в App.svelte). Адреса и названия экранов не менялись |
| Правила шлюза | Список, создание, изменение, выключение/включение; списки — `GET /api/rules/meta`; условие хранится, но помечено «не применяется до этапа 5» |
| Уведомления | Адрес Bot API, ID чата, таймаут HTTP, токен (переход на «Разблокировку»), «Проверить подключение»; по каждому событию: вкл/выкл, площадки, условие (с этапа 5) |
| Журнал | Листание страницами (размер задаёт зритель), фильтры по уровню, виду, площадке (по загруженным записям), живые записи |
| Монеты | Во всю ширину окна (Issue #33). Справочник из ядра (`GET /api/coins`) компактным списком: тикер, адрес коротко, итог отбора (прошла / причины), налоги коротко, пулы «допущено / всего». Фильтры: поиск по тикеру или адресу; итог отбора — прошла, нет сети BSC, нет адреса контракта, нет стакана, нет пула с USDT, крючок, налог, в чёрном списке (вручную), проверка не прошла, не проверено, не оценить, вывод/депозит закрыт, нет направлений (по полям directions, presence[].excluded, block.reason, taxes, pools[].admission, problem — не по тексту); площадка (монета есть в справочнике площадки); есть/нет пулов; вид пула; налоги проверено/не проверено/ошибка; только чёрный список. Щелчок — окно с крестиком (Esc, щелчок мимо): полный адрес с «Копировать», итог отбора, площадки, налоги, чёрный список, причины по площадкам и пулам по строке, пулы с крючками и проверками, номер блока; «Перепроверить» |
| Ручное управление, Статистика газа, Каналы отправки | Данные ядра (`/api/manual`, `/api/gas-stats`, статистика каналов из событий адаптера); команды «Продать сейчас», «Беру на себя», «Вернуть боту» выполняет ядро |
| Живой экран | Во всю ширину окна (Issue #33). Компактная строка на монету, прошедшую отбор (решение 55), без переносов: рядом спред в обе стороны — «купить на A → продать на B» и «купить на B → продать на A» (по каждому: спред % и порог комиссий % — 3 знака, короткое состояние: ниже порога / держится / кандидат / аномалия / нет цены / не задано / пауза), время обновления; много колонок — прокручивается только таблица. Щелчок по строке — окно с крестиком (Esc, щелчок мимо): полный адрес с «Копировать», по направлениям точные цены покупки и продажи (и коротко — 6 значащих), объём сравнения, точный спред и порог, состояние и полная причина — каждая причина с новой строки, сколько держится выше порога, время; окно обновляется вживую. Данные — вживую по сообщениям `spread`; колонки строятся по парам площадок из данных — новая площадка сама добавляет пары в обе стороны; нет данных по направлению — «—» с причиной в подсказке; сортировка по наибольшему спреду из направлений монеты. Кандидаты: прошёл или отказ с причиной, полный список затрат; фильтр по монете и «только выше порога» |
| Сделки | Идущие и закрытые сделки: шаг, где монеты, вложено, выручка, затраты, итог против плана; хронология и план |
| Плашка режима (на всех экранах) | Режим системы «Стоп» / «В работе» / «Пауза» и причина (после запуска — «Стоп» до «Старт», решение 46); кнопки «Старт», «Пауза», «Стоп»; паузы площадок и карантины монет с кнопкой снятия; итог дня |
| Справочник пулов (решение 58) | «Площадки» → DEX: блок «Справочник пулов (индексатор)» — источник и сеть, подпись источника (index.attribution_*), почему не обновляется, сколько монет спрошено и с ошибкой (по монете — причина), пулы с USDT/промежуточными и итог по ним, список DEX индексатора; кнопка «Обновить экран»; данные перечитываются по записи журнала dex.index. Настройки index.* — в «Настройках площадки». «Монеты» → окно монеты: пулы из справочника (DEX индексатора, пара, адрес/PoolId, ликвидность по индексатору, итог бота) и подпись источника |
| Таблица «DEX индексатора → вид пулов» (решение 58) | «Площадки» → DEX: строка — DEX индексатора (имя и id; по умолчанию — с пулами монет или с настройками, «показать все DEX индексатора» — все). В строке: итог по её пулам в справочнике, вид (dex.kind) и включатель (dex.pool_enabled); «Адреса и настройки DEX» — все настройки области «DEX» этой строки и «Скопировать незаданные настройки из …» (перенос из прежних id видов пулов; только настройки из каталога). Устаревшие значения (имени нет в каталоге: dex.enabled, dex.v3_fee_tiers) — блок «Устаревшие настройки DEX» с пометкой и кнопкой «Удалить». Причины «DEX … не подключена» / «не подключена к сделкам: нет своего пути исполнения» (форки, решение 59) / «отклонён: Universal Router … меняет в другом пуле» / «нативный BNB не поддержан» — на «Монетах» в окне монеты |
| Метки отбора DEX (решение 61) | «Монеты»: итог «пулы найдены, загружаются» (Exclusion PoolsLoading) отдельно от «нет пула с USDT»; монетам, которые DEX не искал (нет пары на бирже), DEX-причины не ставятся; «крючок» — только когда исключены все пулы монеты (PoolsExcluded) |
| Налоги не проверены (решение 61) | «Живой экран»: строка монеты с непроверенными налогами видна, состояние «налоги не проверены: <причина ожидания>» (торговли нет, решение 30). «Монеты»: в строке налогов подсказка «ждёт: …», в окне монеты — «Ждёт: <причина>» (нет пула ≥ dex.min_pool_liquidity_usd, нет пула-источника USDT, узел: …, не задана настройка …); значок ⛔ — только у настоящего чёрного списка |
| Глубина пулов (решение 73) | «Монеты» → окно монеты, столбец «Глубина» у каждого пула: покупка и продажа — USDT в полосе ±dex.depth_band_pct и вердикт глубокий / мелкий (с гистерезисом), порог, «полоса прочитана не целиком», почему не считается; «спит» (слушается только добавление ликвидности), «данные недостоверны», сверка с квотером по каждой стороне — покупка и продажа отдельно (не сверена / сверена / расхождение с причиной), подробности площадки (tickSpacing) (GET /api/coins pools[].depth). «Ждёт: …» у налогов — причина по каждому пулу с цифрами. «Настройки» → «DEX»: dex.depth_band_pct, dex.depth_hysteresis_pct (ошибка при сохранении вне 0–100), dex.depth_log_min_s — необязательная: «не задано (необязательная)», в счётчик «не задано» не входит (схема из каталога, поле optional) |
| Промежуточные монеты (решение 52) | «Настройки»: dex.intermediate_enabled и список адресов dex.intermediate_tokens; «Монеты»: пара каждого пула, «маршрут через …», причины отсева по площадкам; «Живой экран»: затраты кандидата по шагам маршрута |
| BNB ↔ WBNB (решение 62) | Отдельного экрана нет, всё — существующими: «Настройки» → DEX — dex.native_wrapped (адрес WBNB) рядом с dex.native_ticker (схема из каталога); «Площадки» → DEX → «Проверить подключение» — часть «Обёртка нативной монеты» (код по адресу, совпадение с WETH() роутеров V2); «Монеты» — BNB с адресом WBNB и пулами WBNB; «Живой экран» и «Сделки» — затрата `WrapGas` (газ WRAP_ETH / UNWRAP_WETH) в списке затрат; «Балансы» — у DEX строка BNB: free — нативный, locked — WBNB |
| Сухой режим и сигналы (решение 74) | Шапка (все экраны): заметная плашка «СУХОЙ РЕЖИМ — ордера и переводы не выполняются» с виртуальным бюджетом или «не задан dry.budget_usdt — сигналов нет», когда dry.enabled = да (components/DryBanner.svelte, значения настроек вживую). «Живой экран»: та же плашка всегда — ещё «обычный режим» или «сухой режим не задан — выключен»; у прошедшего кандидата — метка «СУХОЙ» и раскрытая карточка сигнала (components/SignalCard.svelte): монета и контракт с «Копировать», где купить и продать, количество и средние цены, стакан (лучшая цена, USDT в полосе ±dex.depth_band_pct, уровней, «полоса шире загруженных уровней»), пулы маршрута (глубина по стороне, мелкий, полоса не целиком, блок), прибыль на бюджете, без бюджета — максимальный объём и прибыль, максимальная прибыль, край поиска; ссылки на пару и пул или «шаблон ссылки не задан». «Эпизоды» (pages/Episodes.svelte): число строк задаёт зритель, почему эпизоды не ведутся, занятое место; таблица — монета и направление, сухой, начало, длительность (у открытого идёт), макс. прибыль на бюджете и без, записей, причина закрытия / «открыт», «запись остановлена»; «Просмотр» — окно с записями (время, объём, прибыль, макс. объём и прибыль, лучшие bid/ask, блоки пулов), щелчок — карточка записи и стаканы; «Скачать» — .jsonl.zst. Настройки — категория «Сигналы и эпизоды» |
