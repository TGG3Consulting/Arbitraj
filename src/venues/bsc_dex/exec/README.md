# venues/bsc_dex/exec — исполнение обмена

Прямой обмен в одном пуле (V2, V3, V4) — через Universal Router своей DEX: только в нём есть проверка
реально полученного баланса в той же транзакции (`BALANCE_CHECK_ERC20`, решение 40) и одна схема разрешений (Permit2).
Умный маршрут (решение 38) — через Universal Router PancakeSwap Infinity (`smart.universal_router`): все доли в одном
`execute`, у каждой свой минимум, в конце — проверка баланса на сумму минимумов.

## База проверки баланса и поступления в кошелёк

BALANCE_CHECK_ERC20 проверяет «баланс выходного токена ≥ база + минимум». База читается прямо перед подписью обмена
(после разрешений), а ожидаемые поступления того же токена (депозит с биржи, возврат USDT) не совпадают с обменом
по времени: `wallet/inflows.rs` — адрес депозита ждёт конца обмена и регистрирует поступление, обмен ждёт, пока
поступлений его выходного токена нет, «Зачислен»/«отклонён» или срок `transfer.max_time_s` снимают поступление.
Перевод на кошелёк, о котором бот не знает, так не ловится: факт — по событиям Transfer квитанции; у V2 минимум
выхода проверяет и сам роутер по балансу получателя до и после обмена внутри транзакции.

## Нативная монета BNB (решение 62)

Ядро торгует BNB как монетой с адресом WBNB (core/native.rs); в кошельке и на бирже это нативный BNB. Обёртка — внутри
той же транзакции Universal Router (официальные команды WRAP_ETH 0x0b и UNWRAP_WETH 0x0c обоих UR, exec/ur.rs), а не
отдельной транзакцией: один газ, одно место в очереди nonce, нет второй транзакции, которая может не попасть в блок между
обёрткой и обменом; минимум проверяется в той же транзакции (решение 40).
- Продажа: `execute{value = сумма}` → WRAP_ETH(роутер, сумма) → обмен WBNB → USDT, первый шаг каждой доли платит роутер
  своей точной суммой (V2/V3 — payerIsUser = false, V4 — SETTLE(сумма, false)), разрешений нет → BALANCE_CHECK_ERC20 по USDT.
- Покупка: обмен USDT → WBNB с выходом роутеру → UNWRAP_WETH(кошелёк, сумма минимумов): роутер разворачивает весь
  полученный WBNB и шлёт BNB кошельку, меньше минимума — откат InsufficientETH (вместо BALANCE_CHECK_ERC20: проверяется
  реально полученное роутером).
- Пулы V4 / Infinity (CL, Bin, Uniswap V4) на стороне BNB — отказ NoRoute, котировка их не берёт (`native::pool_ok`): живой
  проверки WRAP/UNWRAP через них нет (пулов Infinity WBNB/USDT у индексатора нет). V2 и V3 — проверены записями узла.
- Перед отправкой продажи — резерв: BNB кошелька − сумма ≥ risk.min_bnb_balance, иначе InsufficientBalance.
- Факт: монеты — по событиям WBNB Deposit(роутер) / Withdrawal(роутер), USDT — по Transfer кошелька.
