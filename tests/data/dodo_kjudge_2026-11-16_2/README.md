## Поправки к server_README.md (факт записи)

- «28 пулов не в /api/coins» — это пулы, которые бот ни разу не прочитал: в реестре бота их нет, а экран «Монеты»
  показывает только пулы реестра (pools/depth_facts.rs all — reg.refs()). В журнале бота они есть («Новый пул …»
  в окнах запуска, KJUDGE_ERROR / ORACLE_NOT_FEASIBLE при приёме пачек).
- TARGET_IS_ZERO у querySell* — не из-за трейдера 0x0: это require V0 > 0 в DODOMath._SolveQuadraticFunctionForTrade
  (цель стороны равна нулю — сторона пустая); у пулов из API так бывает у одной стороны.
- Окна «запуск / перезапуск»: в 4 окнах (10:25, 15:22, 17:02, 17:49) — 684–4857 записей «Новый пул» (приём пулов при
  запуске бота или новых пулов из справочника); в 3 (20:26, 20:41, 20:52) — venue.head_age «Голова сети устарела /
  снова свежая» (узел отставал). В остальных 13 окнах записи о причине нет.
