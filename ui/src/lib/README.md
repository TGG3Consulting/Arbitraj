# ui/src/lib — общий код интерфейса

| Файл | Что делает |
| --- | --- |
| `api.js` | Запросы к REST; ошибка бэкенда → Error с его текстом; отмена (AbortSignal, ошибка `aborted`); GET одного адреса — не больше одного в полёте (вызов во время запроса ждёт общий следующий, ответ — не старше вызова) |
| `flight.js` | Один запрос в полёте для перечитывания (single-flight): вызов во время запроса — один повтор после него; `cancel()` — отмена при уходе со страницы или смене параметров |
| `live.svelte.js` | Одно WebSocket-подключение к `/api/ws`, рассылка сообщений; переподключение по событиям браузера |
| `settings.svelte.js` | Схема, значения настроек и площадки; обновление из живого потока; изменение значения |
| `secrets.svelte.js` | Состояние секретов и список известных (без значений) |
| `router.svelte.js` | Навигация по адресу `#/экран/аргумент` |
| `prefs.js` | Удобства зрителя в браузере (размер страницы); не секреты |
| `labels.js` | Русские подписи вариантов типов бэкенда, показ значений и времени |
| `dex.svelte.js` | Списки адаптера DEX по площадкам: виды пулов и каналы — id областей «DEX» и «канал»; справочник пулов от индексатора (решение 58) |
| `directory.js` | Подписи справочника пулов: итог по пулу, ликвидность коротко |
| `remote.svelte.js` | Данные экрана из одного GET: 503 → «нет данных», перечитывание по живым сообщениям |
| `coinsLive.svelte.js` | «Монеты» (t84): полный список GET /api/coins и обновление одной строки по сообщению монеты (GET /api/coins/{address}) |
| `coinLabels.js` | Показ проверок монет и пулов: налоги, причины чёрного списка, группы крючков, причины отсева на площадке |
| `control.svelte.js` | Режим системы и команды управления (GET/POST /api/control, живое сообщение control) |
| `delist.svelte.js` | Решение 175: делистинги бирж (GET /api/delistings), запись монеты по (площадка, тикер), отметки «делистинг на X: дата» |
| `coreLabels.js` | Подписи данных ядра: режим, состояние направления (полное и короткое, причина отдельно), шаг сделки, направление строкой |
| `liveGrid.js` | «Живой экран» (решение 55): строки по монетам, колонки — пары площадок из данных в обе стороны, сортировка по наибольшему спреду |
| `fmt.js` | Короткий показ: проценты — 3 знака, цены — до 6 значащих, адрес коротко, время, причины по строкам |
| `coinFilter.js` | «Монеты»: итог отбора по структурированным полям /api/coins и фильтры экрана |
| `settingsGroups.js` | «Настройки»: категории из схемы со счётчиками (всего / не задано нигде), поиск во всех категориях, «только незаданные» |
| `dry.svelte.js` | Сухой режим для плашки — как его видит ядро (GET /api/dry, решение 74) |
| `windowLabels.js` | «Окна» (решение 125): отметки итога, длительность, размер, время с мс и мкс (время получения — нс) |
| `uncappedLabels.js` | «Упущено из-за потолка» (решение 141): что ограничило, деньги, период |
| `venueDir.js` | Решение 242: рубрики подпункта «по биржам и направлениям», id области VenueDir, текст «что действует» при незаданной паре (решение 258: у risk.max_daily_loss_usd, venue_role PairVenue, — значение биржи рубрики, у DEX ↔ DEX — DEX) |
