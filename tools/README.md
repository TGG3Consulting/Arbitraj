# tools/

Вспомогательные скрипты, которые запускает Тигран вручную (не часть бота, бот их не вызывает).

- `arbitrum_record/` — запись фактов своего узла Arbitrum (только чтение: eth_call, eth_getLogs, eth_getStorageAt,
  eth_getCode; без ключей и подписей) в `tests/data/arbitrum_<семейство>_<дата>/` для тестов на записанных данных.
