# Фоновая проверка кандидата на продажу

Ядро удерживает интерес к выбранной паре до выхода из предпроверки. Два одновременных направления с теми же кошельком, токеном и поколением настроек делят одну задачу чтения. При завершении последней предпроверки задача освобождает место в очереди узла. В симуляцию передаётся остаток только на том блоке, для которого его проверили.
