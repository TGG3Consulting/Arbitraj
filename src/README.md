# src — код системы

| Папка / файл | Что внутри |
| --- | --- |
| `main.rs` | Запуск: аргументы, база, настройки, журнал, уведомления, веб-сервер |
| `lib.rs` | Список модулей |
| `bin/` | Отдельные программы того же крейта (решение 218: `uncapped_recompute` — пересчёт старых записей «без потолка» по окнам); см. bin/README.md |
| `cli.rs` | Аргументы запуска `--data-dir`, `--listen` (без значений по умолчанию) |
| `core/` | Ядро. Сейчас — общие типы. Ничего не знает о площадках |
| `gateway/` | Шлюз: контракт адаптера, ошибки, события, правила, реестр |
| `venues/` | Адаптеры площадок (появятся на этапе 2) |
| `settings/` | Хранилище настроек |
| `secrets/` | Секреты в памяти |
| `storage/` | SQLite: база, журнал, правила |
| `notify/` | Уведомления в Telegram |
| `api/` | Веб-сервер для интерфейса |

Карта связей — `ARCHITECTURE.md`. Правила — `CLAUDE.md`.
