# Hanji на Base

`live.rs` обслуживает ручную проверку цены через `POST /api/venues/{id}/hanji/quote`. Адреса токенов и рынка должны совпасть в реестре Hanji и в ответе прокси на закреплённом каноническом блоке Base. Глубина включает виртуальные ордера. Их нельзя восстановить из одних событий торгов. [Контракты и ABI](https://docs.hanji.io/for-developers/liquidity-source-integration)

`mod.rs` считает покупку X за Y и продажу X в Y по целым лотам. При покупке из бюджета вычитается комиссия в Y. При продаже из выручки вычитается комиссия в Y. Фактическое округление проверяется с ответом контракта и изменением баланса кошелька. В результате видны и исполненный объём, и остаток. [Единицы, глубина и комиссии](https://docs.hanji.io/for-developers/liquidity-source-integration#simulation)

Адреса, проверенные контрольные суммы и пределы применения перечислены в [общем справочнике сетей](../../../../docs/BASE_ETHEREUM_SETTINGS.md). Исходные вызовы при ручном запросе не меняют состояние рынка. Автоматическая торговля требует штатного учёта транзакции, приёмки адреса исполнения для сети и сравнения полной стоимости с остальными маршрутами.
