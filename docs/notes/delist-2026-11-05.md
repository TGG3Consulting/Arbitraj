# Делистинги — источники по биржам (решение 175, 05.11.2026)

Живой случай: KuCoin снял ION/USDT с торгов 05.11 (сделка 20261105020010981ION, kucoin → mexc) — «разница цены» была
из-за делистинга. Механизм — в ядре для всех бирж: контракт `delistings` (gateway/contract.rs), фоновое обновление
`core/delist.rs` (`delist.refresh_s`), проверка обеих сторон перед сделкой `core/delist_check.rs` (`delist.block_hours`).
«Неизвестно» — не блокирует (одна запись журнала `core.delist`); страховка — отсев PairNotTrading (core/presence.rs).

| Биржа | Источник в API | Что делает адаптер |
| --- | --- | --- |
| Gate | GET /spot/currency_pairs → `delisting_time` («Expected delisting time as a Unix timestamp in seconds», SDK gateapi-python CurrencyPair.md) | Пары к venue.quote_asset с временем > 0; вывода нет. Живая запись 04.11: 34 пары к USDT, 11.11 03:00 UTC |
| Binance | GET /sapi/v1/spot/delist-schedule (MARKET_DATA, вес 100; спецификация binance-api-swagger: подпись, ответ `[{delistTime, symbol: [...]}]`) | Символ → монета по справочнику пар. Страница на сайте документации в сессии не прочитана — разбор строго по спецификации; живой ответ записать |
| CoinEx | GET /v2/spot/market → `delisted_at` («Expected time to be delisted, in milliseconds») | Пары к venue.quote_asset с временем > 0 |
| BingX | GET /openApi/spot/v1/common/symbols → `status` 29 «pre-delisted» (docs-v3) | Запись без времени — ядро отказывает «время не сообщено». `offTime` в ответе есть, смысл не описан (живая запись 24.10: в прошлом при status 1) — не используется |
| KuCoin | Нет у пары (GET /api/v2/symbols). Есть GET /api/v3/announcements (annType delistings) — монета и время только текстом | «Неизвестно» |
| Bybit | Нет в instruments-info (спот). Есть GET /v5/announcements/index (type delistings) — монета и время только текстом | «Неизвестно» |
| OKX | Поле `expTime` в GET /api/v5/public/instruments — официальная страница в сессии не прочитана | «Неизвестно» до сверки |
| Bitget | Поле `offTime` в GET /api/v2/spot/public/symbols — описание не прочитано | «Неизвестно» до сверки |
| Phemex | `timeline` в GET /public/products-plus — поля не прочитаны | «Неизвестно» до сверки |
| MEXC | Нет (exchangeInfo: status 1/2/3) | «Неизвестно» |
| HTX | Нет (v2/settings/common/symbols: state offline — уже снята) | «Неизвестно» |
| XT | Нет (state DELISTED — уже снята) | «Неизвестно» |
| Poloniex | Нет (delisted у монеты — уже снята) | «Неизвестно» |
| Kraken | Нет (AssetPairs status: online, cancel_only…) | «Неизвестно» |

## Вопросы Тиграну
1. KuCoin и Bybit: делистинги есть только в API объявлений текстом. Разбирать текст (монета и дата в заголовке/описании)
   — это не структурные данные; делать ли так для KuCoin (живой случай ION) — решение Тиграна.
2. OKX `expTime`, Bitget `offTime`, Phemex `timeline`: сверить описание полей с официальной документацией и живой записью
   пары в делистинге — тогда включить в адаптеры.
3. BingX `offTime`: что означает (в записи — время в прошлом у торгуемой пары).
4. delist.block_hours не задана — проверка выключена (как у прочих необязательных защит); если нужно «не задано — не
   торговать монету в делистинге вовсе», сказать.
5. Время «по времени биржи» в объявлениях (KuCoin: «05.11 00:00») — API у KuCoin его не даёт; у Gate/Binance/CoinEx —
   Unix-время, часовой пояс не важен.
