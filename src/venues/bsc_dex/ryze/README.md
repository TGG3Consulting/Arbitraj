# Ryze на Base

Котировки поступают от Router. Подписанное поручение получает Relayer. Итог выплаты подтверждает каноническая квитанция.

| Файл | Назначение |
|---|---|
| `book.rs` | Фоновая книга измеренных размеров и краткоживущие персональные котировки. |
| `budget.rs` | Общее окно запросов Relayer, пауза Retry-After и свидетельство отказа подписанного POST. |
| `chain.rs` | Канонические блоки, квитанции и подтверждение состояния nonce. |
| `deployment.rs` | Параметры и проверка контрактов размещения. |
| `execute.rs` | Границы цены, однократная отправка подписанного поручения и сохранение отказа. |
| `fill.rs` | Фактически списанные и полученные активы по логам исполнения. |
| `http.rs` | Раздельный обмен с Router и Relayer с ограниченным временем и размером ответа. |
| `ledger.rs` | Принадлежность nonce и устойчивые данные подписанного поручения. |
| `market.rs` | Состояние рынка и кошелька для выбранного размера. |
| `other.rs` | Проверка расхода nonce другой подписанной заявкой. |
| `preflight.rs` | Проверки допустимости до подписания. |
| `price.rs` | Расчёт платы по пути и проверка ответов Router. |
| `price_tests.rs` | Проверки округления по историческим квитанциям и повторной цены. |
| `recovery.rs` | Сверка исхода по сохранённому digest и канонической истории. |
| `relay_tests.rs` | Потеря подтверждения, повтор и сохранение брони после перезапуска. |
| `result.rs` | Результат сделки и реальные объёмы для учёта. |
| `routing.rs` | Выбор персональной цены среди конкурирующих маршрутов. |
| `service_tests.rs` | Ответы официальных серверов и регрессии отказа HTTP 429. |
| `tests.rs` | Проверка канонических платёжных свидетельств. |
| `tokens.rs` | Привязка ERC20 и реализаций к фактическому блоку. |
| `wire.rs` | Поля EIP-712, кодирование и проверка исходной операции. |
