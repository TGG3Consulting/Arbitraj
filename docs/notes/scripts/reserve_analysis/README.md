# reserve_analysis — разбор запаса на движение цены (решение 240)

Запуск: `python3 run.py --out out` (параметры — `--help`; инструкция и метод — `docs/notes/reserve-analysis-2026-11-09.md`).
Python 3.8+, только стандартная библиотека. Только чтение: бот — GET, узел — eth_blockNumber, eth_getBlockByNumber,
eth_getLogs, eth_call; архивный узел (только если задан `--archive-url`) — eth_getBlockByNumber, eth_getLogs, eth_call.

| Файл | Что делает |
| --- | --- |
| `run.py` | Точка входа: аргументы, порядок шагов, summary.json |
| `common.py` | Decimal, время RFC 3339, квантили, журнал прогресса, запись JSON/CSV |
| `keccak.py` | keccak256 на чистом Python, topic0 событий пулов, самопроверка по записанным ответам узла |
| `botapi.py` | REST бота (GET, Host), кэш, листание журнала с возобновлением |
| `rpc.py` | Транспорт JSON-RPC: предел частоты, общий срок запроса (сторож), журнал каждого запроса |
| `node.py` | Узел: кэш, earliest (самый ранний доступный блок), окна getLogs, блок по времени, архив (--archive-url) |
| `earliest.py` | Самый ранний блок, который отдаёт узел (бинарный поиск, перепроверка), причина «блок старше …» |
| `nodeinfo.py` | `--node-info`: диагностика узла (голова, earliest, ответы на заданные блоки) |
| `settings_at.py` | Значения настроек на момент строки по истории, область «площадка · направление», пороги |
| `checks.py` | Проверки: порог сделки на её момент, «как сейчас», текущие значения |
| `pools.py` | Изменение цены маршрута DEX по событиям пулов (V2, V3, CL-синглтон) |
| `records.py` | Отказы, эпизоды, чистые сделки |
| `dexmove.py` | T_real по сделкам, исход отказов биржа → DEX, проверка модели на сделках |
| `reserve.py` | Формула запаса бота и её варианты настройками |
| `evaluate.py` | Перебор значений настроек, итог на истории, лучшие значения |
| `report.py` | Сводки (А), (Б), проверка метода, CSV |
| `summary_text.py` | README.txt выхода и краткая сводка в консоль |
