# Папка запуска для Linux

Кладётся в архив `arb-linux` сборкой `.github/workflows/linux.yml` (статический бинарь под musl —
запускается на любой версии Linux/Ubuntu независимо от glibc).

- `arb` — бинарь (статический, x86_64-unknown-linux-musl).
- `ui` — собранный интерфейс.
- `start.sh` — запуск: папка данных `data` рядом, интерфейс на `http://127.0.0.1:8787` (только этот сервер).
  Аргументы запуска — `src/cli.rs`; порт и размер буфера живых потоков можно поменять прямо в `start.sh`.

Запуск:

```
chmod +x arb start.sh
./start.sh
```

На сервере интерфейс наружу не открывать — заходить через SSH-туннель или VPN.
Автозапуск как сервис (systemd) — по желанию, отдельно.
