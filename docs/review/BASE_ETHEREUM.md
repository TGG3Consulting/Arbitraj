«профиль не установлен»; (4) порядок — по объёму DefiLlama, не по числу строк страницы (20 — это потолок страницы).

## R-05 · 🟡 · Base: USDT против USDC — заработает ли сеть вообще
В TASKS.md: «Полный денежный цикл на Base требует исполнимой конверсии USDC в USDT». Учётная валюта — USDT, а основная
ликвидность Base — в парах с USDC и WETH. Вопросы по фактам, без них непонятно, будут ли сделки:
1. Какая доля пулов Base из профилей отсечётся первичным фильтром «пул с USDT», если USDC не задан промежуточной
   монетой (`dex.intermediate_tokens`, решение 52)? Есть ли цифра по снимку?
2. Как идёт деньги по кругу биржа → Base → биржа: какие из подключённых бирж выводят/принимают USDT в сети Base, а какие
   только USDC (по их API сетей)? Если USDT на Base не выводится — возврат USDT (usdt_return) не сработает.
3. Где в учёте конверсия USDC↔USDT: отдельная нога маршрута с её комиссией пула и проскальзыванием, или нет?
Предлагаю перед профилями «хвоста» DEX (R-01) закрыть этот вопрос — от него зависит, есть ли на Base деньги вообще.
