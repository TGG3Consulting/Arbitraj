# storage — хранение

| Файл | Что делает |
| --- | --- |
| `db.rs` | Открывает SQLite (`<data-dir>/arb.sqlite`), создаёт таблицы, выполняет запросы в отдельном потоке |
| `journal.rs` | Журнал: запись + живой поток в интерфейс |
| `rules.rs` | Правила шлюза: список, создание, изменение |
| `wallet_queue.rs` | Состояние очереди кошелька DEX (переживает перезапуск) |
| `venue_state.rs` | Найденные адаптером факты, которые не нужно искать заново (площадка, вид, id → значение) |

Таблицы: `settings`, `settings_history`, `rules`, `journal`, `wallet_queue` (очередь кошелька DEX — площадка, JSON состояния), `venue_state` (факты адаптеров: блок развёртывания контракта, история пулов V4 — площадка, вид, id, значение), `daily_result` (итог дня по датам: фактический и предварительные убытки сделок — core/daily.rs, решение 53), `core_state` (учёт ядра: сделки, переводы, газ, ручное управление — вид, id, JSON; core/persist.rs). Сырые сообщения — файлы zstd (raw_log.rs).
