# Комиссия вывода Poloniex на BSC

`ledger.json` — проекция двух сохранённых записей одной завершённой операции 22 ноября 2026 года. Отправитель назвал валюту вывода и комиссии BSC. Получатель зачислил BNB. У обеих записей один хеш. Из 0,71650811 BNB после комиссии 0,00078059 BNB пришло 0,71572752 BNB. В файле хеш транзакции и идентификаторы заменены непрозрачными значениями с сохранением их равенства. Кошельки и ключи отсутствуют. Тест восстанавливает контекст создания из сохранённого актива, сети вывода и идентификатора. Исходного приватного кадра в записи нет.

`currencies.json` сохраняет поля `coin`, `networkList.coin`, `blockchain` и `contractAddress` для BNB, RACA и USDT из публичного GET /v2/currencies от 23 ноября. У RACA сети Ethereum и BSC имеют одинаковый адрес контракта и разные сетевые имена. Описание суммы, комиссии, истории и сетевых имён публикует биржа. [История операций](https://api-docs.poloniex.com/spot/api/private/wallet#wallets-activity-records), [справочник](https://api-docs.poloniex.com/spot/api/public/reference-data#currencyv2-information).
