# venues/bsc_dex/check — проверки монет и пулов (решения 30, 32)

Пока проверка не завершена — торговли нет: котировка отвечает `CoinNotChecked` / `CoinCheckFailed`.

| Файл | Что делает |
| --- | --- |
| `state.rs` | Итоги в памяти: налоги монет, газ обмена по пулу, влияние крючка, сверка с квотером |
| `simulate.rs` | `eth_simulateV1`: цепочка вызовов в одном блоке без подписи (execution-apis) |
| `native_probe.rs` | BNB (решение 62): после обычной пробы WBNB — покупка с UNWRAP_WETH, продажа с WRAP_ETH (value) и нативный перевод в одном eth_simulateV1: газ обёртки сверх обмена токеном и газ нативного перевода |
| `probe.rs`, `probe_calls.rs` | Пробный обмен в любом пуле тем же путём, что сделка (Permit2 + Universal Router): налог покупки, продажи, перевода; газ обмена, разрешений и перевода |
| `taxes.rs` | Проверка монеты: пробы по всем пулам (V2 впереди), источник USDT — другой пул V2/V3 реестра |
| `hooks_probe.rs` | Влияние крючка V4 группы B/C: квотер (исполняет крючок) против математики |
| `cycle.rs` | Циклы налогов (`tax.recheck_interval_s`) и крючков (`hooks.recheck_interval_s`), события CoinCheck / PoolCheck |
| `quoter_cycle.rs` | Цикл сверки с квотером (`dex.quoter_check_s`) всех пулов; у пулов с крючком B/C — за вычетом измеренного влияния |
| `tax_cycle.rs` | Цикл налогов: первый проход после стартовой загрузки пулов, сводка и CheckPass ядру; полный проход раз в tax.recheck_interval_s; между ними — «Перепроверить» (только переданные), «пул готов», повтор после сбоя узла (tax.retry_s) |
| `tax_pass.rs` | Проверка списка монет: Known/Failed — ядру; ждущие (нет пула, узел, настройка) — не вердикт; журнал только на смену состояния |
| `taxes_util.rs` | Налоги в процентах по замеру пробы и источник встречного токена для пробы |
| `quoter_tally.rs` | Сводка первого прохода сверки с квотером (прошли, исключены, мелкие, частые причины) |
| `recheck.rs` | Очереди «Перепроверить» (только переданные монеты) и «новые пулы» для трёх циклов |

«Кто меняет» (`emitter.rs`, решение 59): в пробном обмене покупки и продажи событие обмена должно быть от самого пула
(V2/V3 — его адрес; V4/Infinity — менеджер и topics[1] = PoolId); иначе пул исключён (справочник — «отклонён»).
