# ARB — спотовый арбитраж BingX ↔ DEX в сети BSC

Система покупает монету там, где она дешевле, переводит по сети BSC и продаёт там, где дороже — только если прибыль после всех затрат выше порога.
Первый этап: биржа BingX ↔ DEX в сети BSC (PancakeSwap, Uniswap) через свой кошелёк. Дальше — Gate, MEXC и другие.

## С чего начать
1. `CLAUDE.md` — миссия, ценности и жёсткие правила. Читается перед любой работой.
2. `ARCHITECTURE.md` — слои, контракт адаптера, путь одного тика, готовые фичи.
3. ТЗ и полный флоу: https://claude.ai/artifact/Ar8D2mdQ2TYFQx7V8nsRei
