# secrets — секреты

Ключи бирж, ключ кошелька, токен Telegram — в зашифрованном файле `<data-dir>/secrets.enc`, расшифровка паролем, значения только в памяти.

| Файл | Что делает |
| --- | --- |
| `crypto.rs` | Argon2id (ключ из пароля) + XChaCha20-Poly1305, формат файла |
| `file.rs` | Чтение и атомарная запись файла |
| `vault.rs` | Секреты в памяти: создать, разблокировать, заблокировать, изменить, сменить пароль |

Подробности — `docs/SECURITY.md`, решение №27.
