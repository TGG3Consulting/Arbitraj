# Сторож пар (решение 202) — биржи, 06.11.2026

Сторож работает только у биржи, где **по официальной документации** кадр стакана приходит по расписанию и без изменений:
тогда тишина пары при живом соединении означает, что подписка пары умерла. Где кадры идут только при изменениях
(или документация расписание не гарантирует), тишина неликвидной пары — норма: сторож там не включён, иначе он
переподписывал бы живые пары по кругу. Источник по каждой бирже — шапки файлов адаптера (ссылки на документацию).

## Что не сделано / вопросы
- Для бирж «не проверено» нужно прочитать официальную документацию канала стакана (гарантировано ли расписание
  без изменений) — до этого сторож там не включается (правило «никогда не гадать»).
- Время «Обновлено» строки «Живого экрана» (core/evaluate.rs) ставится при каждом расчёте направления; кадр стакана без
  изменений ядру не отдаётся (решение 109), поэтому у неликвидной пары время строки может стоять, хотя поток жив.
  Ядро не менялось.
