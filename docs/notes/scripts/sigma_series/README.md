# sigma_series — «было / стало» для σ запаса на движение цены (задача t177)

Запуск из этой папки: `python3 -B run.py [папка выгрузки]` (по умолчанию tests/data/sigma_windows_2026-11-16).
Python 3.8+, только стандартная библиотека, только чтение файлов. Итог и выводы — docs/notes/t177-sigma-series-2026-11-17.md.

| Файл | Что делает |
| --- | --- |
| `run.py` | Точка входа: A — сделки (запас плана против факта, сделки с σ = 0), B — окна стакана (варианты σ по истории окна против падения цены продажи за T, критерий решения 360), C — скачок в истории и что было дальше |
| `series.py` | Ряды цены продажи из кадров (VWAP объёма сигнала, лучший бид, VWAP объёма сделки) и оценки σ кода, σ_T, σ без наибольшего шага, ρ₁ — формулы vol.rs и vol_horizon.rs |
| `data.py` | Чтение выгрузки (кадры, сделки, настройки), значение настройки по области «площадка:тип → площадка → вся система», медианы плана |
