# Наблюдения узла при чтении баланса

Адаптер сопоставляет `eth_createAccessList` для кошелька сделки и контрольного держателя на одном каноническом блоке. В ответах связаны адрес контракта хранения и ключ конкретного держателя. Обычная симуляция проверяет, сколько токенов действительно может продать кошелёк. [Документация Geth](https://geth.ethereum.org/docs/interacting-with-geth/rpc/ns-eth)
