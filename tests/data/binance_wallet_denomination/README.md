# Пример Binance Wallet

Поля для парсера взяты из опубликованного примера ответа 200 на GET /sapi/v1/capital/config/getall в документации Binance. Одна биржевая единица 1MBABYDOGE соответствует 1 000 000 токенов BABYDOGE на указанном контракте BSC. Пример иллюстрирует формат. Перед сделкой адаптер читает действующий справочник аккаунта. [All Coins' Information](https://developers.binance.com/docs/wallet/capital/all-coins-info)
